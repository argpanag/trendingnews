Epic releases new launcher for Linux, thanks to “vibe coding”

TheTools · 16.10.2026 01:04 · source · permalink

With major help from AI agents, the new Epic Games Store launcher is available for Linux as a preview. Fortnite is also set to be ported.

(Image: Epic Games)

  • Martin Holland

Epic has released a Linux version of the new launcher for its Games Store for testing. In a blog post, the U.S. game maker says the software is the result of “vibe coding” and significantly outperforms the old launcher and the competition in speed. The first release is still missing a number of features; Epic writes, “Think of it as a speedboat and not a yacht!” Epic also plans to make the popular battle royale shooter Fortnite available for Linux, but the team responsible has not provided a timeline. Epic says the launcher officially supports Ubuntu 22.04 LTS and later, Fedora 43 and later, and Debian 12 and later.

Built by AI agents

An Epic employee first made it public in mid-August that Epic was working on a native Linux version of its Games Store launcher without giving a release date. The blog post now suggests that AI support has significantly accelerated the work. In an interview with The Verge, Epic Games Store head Martin Keely said the AI technology had been “super helpful.” That applied to testing the software and recreating core launcher features. AI enabled Epic to offer the launcher for Linux as well. The team worked on it for most of the year, with AI agents writing and reviewing the code. People guided them. But the directive that Epic “doesn’t want to see any handwritten code” did not apply here.

According to the announcement, the new launcher should start noticeably faster and respond more quickly, too. It supports voice chat and includes numerous other improvements. To make Fortnite available for Linux as well, Epic is working on porting its EAC anti-cheat tool. Epic is coordinating with distribution maintainers on security requirements. Once EAC works with a “critical mass” of them, Fortnite will launch on Linux through the launcher. Epic also plans to help other game studios bring their titles to Linux. Steam has been the pioneer in this area so far, but GOG recently announced that it, too, is working on a Linux version of its launcher.

Until now, the Epic Games Store client has been available only for Windows and macOS. During the preview, Epic still recommends that competitive players and developers with active projects use the old launcher. Anyone who wanted to manage their Epic library on Linux systems such as Valve’s SteamOS had to turn to third-party software like Heroic Games Launcher. This open-source program integrates the Epic library through the Legendary command-line tool and runs Windows games using Proton or Wine. In an FAQ, Epic now says that many games are available only as Windows builds and may need a compatibility layer to run on Linux. That means the alternatives will remain useful.
