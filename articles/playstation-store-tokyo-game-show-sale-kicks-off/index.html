PlayStation Store Tokyo Game Show Sale Kicks Off

TheTools · 09.09.2026 20:30 · source · permalink

Sony has kicked off the latest PlayStation Store sale, called the Tokyo Game Show (TGS) promotion, which, surprisingly, doesn’t focus only on Japan-owned game companies.

While there are a significant number of discounts, the biggest deals include the re-release of Black Ops and Black Ops 2, Capcom’s Pragmata,and a slew of Resident Evil titles.

For the complete list, and our recommendations, read on.

PlayStation Store TGS Sale Now Live – Ends 9/23
