Here's how to save your game in GTA 6

TheTools · 18.11.2026 18:00 · source · permalink

As with past games, GTA 6 features manual saving, letting you choose when you want to create a checkpoint you can return to. In a game with many chapters and missions, this is especially useful in case you want to try things a different way and reload.

There are 15 manual save slots you can use—I'd suggest keeping one save at the start of each chapter if you want full potential coverage to go back to previous points. To save the game you need to:

  1. Open the main menu
  2. Select the "Game" option
  3. Choose the "Save Game" option

Voila, you've saved your game in GTA 6. You can load game via this same menu, too. Remember, that there are certain things in-game that will disable saving entirely, such as if you start using cheats. You'll have to quit out and return to be able to save again, but since cheats aren't available early on, you don't have to think about that right now.
