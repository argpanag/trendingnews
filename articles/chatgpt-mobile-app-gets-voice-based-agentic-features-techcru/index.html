ChatGPT mobile app gets voice-based agentic features | TechCrunch

TheTools · 23.09.2026 17:00 · source · permalink

Posted:

  • Ivan Mehta

OpenAI announced on Wednesday that it is bringing voice-based agentic features to mobile, allowing users to trigger workflows like drafting documents or summarizing emails.

Plus and Pro users will be able to use the Work tab on their phone to create a document, draft an email, or summarize Slack messages, for instance. These subscribers can do things like build sites, create presentations, use the cloud browser, and also access other areas like finances in ChatGPT. Free and Go users, meanwhile, will get to work with plugins and connected apps.

OpenAI said ChatGPT’s voice conversations will have richer text output. Plus, users will be able to switch between text and voice easily. They can also start working on a conversation on the go and resume it on desktop.

The feature arrives as an increasing number of users are turning to voice to issue commands to AI assistants for complex tasks.

In July, OpenAI launched its new conversational model GPT-Live, and later the company integrated it with the desktop app to let users use their voice to complete tasks in the Work tab or build apps in the Codex tab. The new rollout brings similar capabilities to the mobile app.

Recently, Anthropic made the handoff between mobile and desktop easier and also merged its Cowork and Chat interface. But OpenAI is still keeping chat and workspaces separate.
