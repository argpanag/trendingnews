PS5 System Update 26.07-14.23.00 Released With Security Fixes Ahead of GTA VI Launch

TheTools · 17.11.2026 07:15 · source · permalink

Sony has released PS5 system update 26.07-14.23.00, bringing another round of security fixes to the console. The official patch notes are brief, mentioning only “security fixes to the system software” without explaining what vulnerabilities have been addressed.

The new firmware follows version 26.07-14.22.00, which arrived in early November with the same patch notes. Both updates have been released shortly before the November 19 launch of Grand Theft Auto VI, although Sony has not indicated whether either update is related to the game.

The timing also comes amid renewed activity in the PS5 homebrew community. Following the widespread “Relapse” exploit affecting firmware 13.60, security researcher Gezine recently claimed to have dumped a game binary on firmware 14.22. That version is reportedly required to run GTA VI, making the claim particularly relevant ahead of the game’s release.

No public jailbreak has been released for the affected firmware, and preloaded GTA VI files remain encrypted until launch. However, the possibility of accessing a game binary before release has raised concerns about an early leak or attempts to reverse-engineer the game using AI-assisted decompilation tools. Such an effort could potentially lead to an unofficial PC port, although there is no confirmation that this has happened.

Beyond security patches, Sony has also been working on visual improvements for the PS5. Recent updates introduced Quick Spectral Super Resolution (QSSR) to the standard console, an AI-based upscaling technology developed with AMD and derived from the PS5 Pro’s PlayStation Spectral Super Resolution (PSSR).

The technology is already being used to improve image stability in Marvel’s Spider-Man 2, with support expanding to other games, including Control Resonant, ARC Raiders, and The Finals.
