This Simulation Game Lets You Play With Video Game Interfaces

TheTools · 19.09.2026 08:00 · source · permalink

If you love clicking buttons, this game is for you.

Video Game Menu: The Game is a fun and experimental game that will have you playing with video game interfaces, starting with a standard menu that turns into a surreal nightmare of impossible settings.

If your favorite part about games is clicking the menu, then this game is for you. With buttons, toggles, sliders, and input fields, it's just menu after menu.

Sebastian Gioseffi

Sebastian Gioseffi

These are some of the features in the game:

  • Over 70 completely legit settings to adjust.
  • A novel-length historical commentary on the height of the Roman Empire.
  • A ridiculous number of useless difficulty options.
  • A Faustian UI nightmare.
  • Bunnies, trumpets, and a decapitated alpaca.
  • UI-related puns and rhymes galore.

Sebastian Gioseffi

The game's length is 20-30 minutes, and it's available in English and Spanish. It was developed by Sebastián Gioseffi, an indie Game Developer from Argentina.

Gioseffi explained that the game keeps humor at its core and "subverts expectations and challenges preconceptions about menus, options, and video games in general."

Video Game Menu: The Game is set to be released on September 21, 2026. You can add it to your wishlist on Steam.
