Grizzlies' Jahmai Mashack: Starting Saturday

TheTools · 22.11.2026 03:00 · source · permalink

Mashack will start Saturday against the Timberwolves.

Mashack, who has been sparsely deployed this season, will get the start with Cameron Boozer (ankle) unavailable. Joining Mashack in the first unit for Saturday's game will be Ty Jerome, Cedric Coward, Jaylen Wells and Zach Edey.
