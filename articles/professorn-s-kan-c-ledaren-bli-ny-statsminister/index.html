Professorn: Så kan C-ledaren bli ny statsminister

TheTools · 25.09.2026 05:20 · source · permalink

Det säger statsvetarprofessorn Mikael Gilljam som lanserar ett oväntat namn som statsminister: Elisabeth Thand Ringqvist.

Så här skulle Centerledaren kunna ta över landet.
