Genoa-Milan, code infinite ai tornelli del Ferraris: disagi anche in Gradinata Nord - Primocanale.it - Le notizie aggiornate dalla Liguria

TheTools · 08.11.2026 14:24 · source · permalink

Attualità

Ancora lunghe code ai tornelli dello stadio Luigi Ferraris in occasione di Genoa-Milan. Un problema che si ripresenta ormai da tempo e che continua a creare disagi ai tifosi intenzionati a raggiungere il proprio posto sugli spalti prima del fischio d’inizio.

Se fino a oggi le maggiori criticità erano state segnalate soprattutto agli ingressi della Gradinata Sud, questa volta i forti rallentamenti hanno interessato anche la Gradinata Nord, con lunghe file di sostenitori rossoblù in attesa di superare i controlli.

Un problema che si ripete e che sembra non trovare soluzione. L’accesso allo stadio continua a rappresentare un momento complicato per molti tifosi, costretti a lunghe attese nonostante l’arrivo agli ingressi prima dell’inizio della partita.
