77-Jährige überfährt 88-Jährige: Tödlicher Unfall auf Berliner Friedhofsparkplatz

TheTools · 10.11.2026 14:33 · source · permalink

© Daniel Karmann/dpa

Am Dienstagvormittag rangiert eine 77 Jahre alte Frau mit ihrem Auto auf einem Friedhofsparkplatz. Dabei erfasst sie eine 88-jährige Fußgängerin.

Stand: heute, 15:33 Uhr

Bei einem Unfall auf einem Friedhofsparkplatz im Berliner Bezirk Lichtenberg ist eine 88 Jahre alte Fußgängerin gestorben.

Wie die Polizei auf der Plattform X mitteilte, war sie am Dienstagvormittag von dem Auto einer 77-Jährigen überrollt worden, als diese auf dem Parkplatz rangierte. Die 88-Jährige starb noch am Unfallort in der Konrad-Wolf-Straße. Ein Verkehrsunfallkommando habe die Ermittlungen aufgenommen. (dpa)
