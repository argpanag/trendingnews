83-jährige Autofahrerin landet auf Kreisel – sie hat keinen Führerausweis

TheTools · 24.10.2026 14:24 · source · permalink

Däniken SO

Beim Unfall wurde niemand verletzt.

Kantonspolizei Solothurn

Am Freitagnachmittag ereignete sich auf der Hauptstrasse in Däniken SO im Bereich des «Däniker Kreisels» ein Selbstunfall. Verletzt wurde niemand.

Am Freitag, kurz vor 15.30 Uhr, war eine 83-jährige Autofahrerin auf der Oberdorfstrasse in Däniken SO unterwegs. Sie beabsichtigte, beim «Däniker Kreisel» in die Hauptstrasse in Richtung Gretzenbach einzubiegen, wie die Kantonspolizei Solothurn in einer Mitteilung schreibt.

Demnach verlor die Seniorin die Kontrolle über ihr Fahrzeug, fuhr geradeaus und kam schliesslich auf der Kreiselinsel zum Stillstand. Verletzt wurde bei diesem Unfall niemand. Gemäss ersten Erkenntnissen dürfte die Frau nicht im Besitz eines gültigen Führerausweises sein.
