Luas Red Line services back running after power failure

TheTools · 01.10.2026 06:18 · source · permalink

Getty

Luas Red Line services are back operating, following a power failure on the line earlier this morning.

All services on the Red Line were previously suspended.

Passengers have been advised to expect delays on the Red Line this morning as normal service resumes.

In a post on social media, Luas apologised for any inconvenience caused.

Passengers please be advised all Red Line services are back operating following earlier power failure. Please expect delays as we work to get the Red Line back to normal service. We apologise for any inconvenience caused. @TFIupdates

— Luas (@Luas) October 1, 2026
