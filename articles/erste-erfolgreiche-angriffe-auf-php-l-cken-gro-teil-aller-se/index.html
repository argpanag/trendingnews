Erste erfolgreiche Angriffe auf PHP-Lücken, Großteil aller Server noch immer ungeschützt

TheTools · 30.10.2026 08:22 · source · permalink

PHP2Shell

Selbst bei aktuellen PHP-Versionen teilweise erst die Hälfte aller Systeme aktualisiert. Österreich schneidet deutlich besser als der weltweite Schnitt ab

Im Code von PHP steckten zwei grobe Lücken, die weite Teile des Internets bedrohen.

Deutlicher können die Warnungen eigentlich nicht mehr sein. Als vor knapp einer Woche zwei kritische Sicherheitslücken in der für Webanwendungen viel genutzten Programmiersprache PHP bekannt wurden, gab es von Expertinnen und Experten unmissverständliche Ratschläge: Entweder die betreffenden Server umgehend aktualisieren oder sie aus Sicherheitsgründen vom Netz nehmen, bis man den Update-Prozess abgeschlossen hat. Ansonsten sei es nur eine Frage der Zeit, bis sich Angreifer auf den eigenen Servern breit machen, und damit Zugriff auf all die dort gespeicherten Daten zu erhalten.

Sie entscheiden darüber, wie Sie unsere Inhalte nutzen wollen. Ihr Gerät erlaubt uns derzeit leider nicht, die entsprechenden Optionen anzuzeigen.

Bitte deaktivieren Sie sämtliche Hard- und Software-Komponenten, die in der Lage sind Teile unserer Website zu blockieren. Z.B. Browser-AddOns wie Adblocker oder auch netzwerktechnische Filter.
