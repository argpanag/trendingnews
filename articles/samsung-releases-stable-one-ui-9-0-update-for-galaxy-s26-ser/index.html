Samsung Galaxy S26 Running One UI 9.0 (Android 17)


Samsung debuted the One UI 9.0 update by opening the beta program for the Galaxy S26, Galaxy S26+, and Galaxy S26 Ultra in May. Now, after almost five months and seven beta releases later, the company has released the stable update for the three phones.

The stable One UI 9.0 update, based on Android 17, has been released for the Galaxy S26, Galaxy S26+, and the Galaxy S26 Ultra in South Korea with firmware version S94xNKSU4BZ16 and a download size of around 550MB for beta-testers. For all other users, the update could have a much bigger download size.

The update, which also includes the September 2026 security patch, could be released in other countries within the next few days.

If you have a Galaxy S26 series phone, you should keep checking for the new update. To do that, open the Settings app on your eligible phone, scroll down and tap Software update, and then tap the Check for updates button. If the update is available in your country, it will start downloading the new software.

Once the new software is downloaded, tap Restart. Your phone will restart after a few minutes, and you can then start using One UI 9.0. Make sure that your phone has more than 30% battery charge left, so that you can start installing the update as soon as it arrives.
