Personel Batalyon A Pelopor Satbrimob Polda Jambi Padamkan Karhutla di Sungai Bertam | Tribrata News Polda Jambi

TheTools · 08.10.2026 07:13 · source · permalink

MUARO JAMBI – Personel Batalyon A Pelopor Satbrimob Polda Jambi melaksanakan pemadaman dan pendinginan kebakaran lahan di Desa Sungai Bertam, Kecamatan Jambi Luar Kota, Kabupaten Muaro Jambi, Rabu (7/10/2026) malam.

15 (lima belas) personel dan 1 unit water cannon dikerahkan untuk melakukan pemadaman di lokasi lahan yang terbakar. Personel di lapangan berupaya memadamkan api sekaligus melakukan pendinginan terhadap area yang terbakar.

Pendinginan dilakukan untuk memastikan titik-titik api benar-benar padam serta mencegah munculnya kembali api yang berpotensi menyebabkan kebakaran meluas ke area lainnya.

Kabid Humas Polda Jambi Kombes Pol. Erlan Munaji, S.I.K., M.Si., mengatakan, upaya pemadaman dan pendinginan tersebut merupakan bentuk respons cepat personel dalam menangani kebakaran lahan sekaligus mengantisipasi meluasnya dampak kebakaran.

“Personel Satbrimob Polda Jambi terus melakukan upaya pemadaman dan pendinginan di lokasi untuk memastikan api benar-benar padam. Langkah ini penting dilakukan guna mencegah munculnya kembali titik api dan mengantisipasi agar kebakaran tidak meluas,” ujar Kombes Pol. Erlan Munaji.

Kabid Humas menegaskan, penanganan karhutla membutuhkan sinergi seluruh pihak serta kepedulian masyarakat untuk tidak melakukan aktivitas yang dapat memicu terjadinya kebakaran lahan.

“Kami mengimbau masyarakat agar bersama-sama menjaga lingkungan dan tidak melakukan pembakaran lahan. Apabila menemukan adanya titik api atau kebakaran, segera laporkan kepada petugas agar dapat ditangani dengan cepat,” pungkas Kabid Humas.
