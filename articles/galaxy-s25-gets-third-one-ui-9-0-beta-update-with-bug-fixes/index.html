Samsung has released the third One UI 9.0 beta update for the Galaxy S25 series. It only brings bug fixes to the phones and no new features.

The third One UI 9.0 beta update for the Galaxy S25, Galaxy S25+, and the Galaxy S25 Ultra is now available in South Korea. It comes bearing firmware version S93xNKSUCZZID and a download size of over 550MB. It does not include the September 2026 security patch.

The changelog is listed below.

If you have enrolled your Galaxy S25 series phone in the One UI 9.0 Beta Program, you should check for the new update by opening the Settings app, navigating to Software update, and tapping the Check for updates button. Your phone should have at least 30% battery charge left.
