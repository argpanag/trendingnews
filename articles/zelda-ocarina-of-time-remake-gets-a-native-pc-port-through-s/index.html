Zelda: Ocarina of Time Remake Gets a Native PC Port Through Static Recompilation

TheTools · 09.11.2026 05:23 · source · permalink

Sunday, November 8th 2026 Zelda: Ocarina of Time Remake Gets a Native PC Port Through Static Recompilation A GitHub developer going by tangerineturtle1 has released NX2navi, a native Windows port of the new Zelda: Ocarina of Time remake built through static recompilation. Rather than emulating Switch 2 hardware, it converts the game into x86-64 code before you play, then draws everything through a custom Vulkan renderer. No game files are included, so players need their own dump of version 1.1.1, and the launcher then builds the game locally, which takes 10 to 25 minutes the first time. RTX owners get DLSS, while FSR 3.1 and its frame generation work on any GPU, and HDR is supported too. Resolution goes beyond 1440p to 5K, frame rate can be uncapped or set as high as 240 FPS (60 FPS is the default), and 21:9 or 32:9 ultrawide screens are supported with the HUD kept at 16:9. The remake only launched last week, and it was already running through an emulator on launch day, albeit poorly. NX2navi is much further along, but it is still labeled early development. Visual bugs, the occasional crash and brief stutters when entering new areas are listed as known issues. It also needs 16 GB of RAM, about 30 GB of storage and a GPU with Vulkan 1.3 and mesh shader support. An earlier showcase on an RTX 5090 reportedly used 18.6 GB of VRAM, though a newer showcase claims memory use is way down. Fan-made PC ports aren't new, as RecompLauncher alone lists nearly 200 of them. Zelda 64: Recompiled brought Majora's Mask to PC in 2024, and Unleashed Recompiled did the same for the Xbox 360 version of Sonic Unleashed last year. An emulator mimics the console and translates the game's instructions on the fly, which costs performance. Static recompilation does that translation once, ahead of time, so the result runs as a regular PC program that's easier to optimize, though it takes more work per game. However, those projects revived games well over a decade old, while this is a full-price release that's barely a week old, and Nintendo has a long history of going after this sort of thing. Yuzu's developers agreed to pay $2.4 million and shut down in 2024, Ryujinx went offline months later after Nintendo contacted its lead developer, and a court recently ordered a Reddit moderator to pay $4.5 million over Switch piracy. Dumping the game generally means jailbreaking a Switch 2, and nothing stops people from using copies they never bought. For a lot of players, this probably ends up being plain piracy. Even the project's own README tells users not to share their builds, which says a lot about the legal risk involved. Sources: NX2navi (GitHub), chasm on X, via Notebookcheck
