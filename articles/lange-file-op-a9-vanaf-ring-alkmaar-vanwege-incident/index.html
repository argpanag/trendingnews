Lange file op A9 vanaf ring Alkmaar vanwege incident

TheTools · 23.11.2026 08:45 · source · permalink

Er staat maandag al de hele ochtend een lange file op de A9 vanaf de ring Alkmaar richting Amsterdam. Er is sprake van stilstaand verkeer op de hoofdrijbaan tussen de afrit Heerhugowaard en de Wijkertunnel vanwege een incident op een aansluitende weg.

De file is ongeveer 11 kilometer lang met een vertraging van ruim een uur. De openbaar vervoer staking van maandag helpt daarbij ook bepaald niet.
