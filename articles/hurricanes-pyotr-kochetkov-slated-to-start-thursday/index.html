Hurricanes' Pyotr Kochetkov: Slated to start Thursday

TheTools · 01.11.2026 21:02 · source · permalink

Kochetkov is expected to start Thursday's home game against the Blue Jackets, Peter Dewar of the Hurricanes' official site reports.

Kochetkov has had a stellar start to the 2026-27 campaign, and he's set to start a third consecutive game Thursday. Across his eight starts to begin the regular season, he's gone 8-0-0 with a 1.61 GAA and .918 save percentage.
