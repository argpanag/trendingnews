V-toppen kritisk till C:s inställning: ”Orimligt att de får diktera villkoren”

TheTools · 24.09.2026 18:47 · source · permalink

Vänsterpartiets vice partiledare Ida Gabrielsson anklagar Centerpartiet för att inte kunna bestämma sig för om de vill samarbeta med oppositionen eller Tidöpartierna.

I ett långt inlägg på X betonar hon bland annat på nytt att V kräver en plats i regering, något som C sagt nej till. V-toppen skriver att partiet säger ja ”till hela regeringsunderlaget”.

”Att vi som vann valet ska låta ett parti ensamt få diktera villkoren är orimligt”, skriver hon.

Gabrielsson menar att det vore ett ”självmordsuppdrag” för C att ”byta sida” och stötta en högerregering.

”Det finns inte tillräckligt med moderata stödröster för att ta in två ’liberala’ partier på den högernationalistiska sidan”, står det i hennes uttalande.
