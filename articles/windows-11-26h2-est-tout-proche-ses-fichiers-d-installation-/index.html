Windows 11 26H2 est tout proche, ses fichiers d’installation apparaissent déjà chez Microsoft - GinjFo

TheTools · 29.09.2026 14:39 · source · permalink

On vous dit tout !

Le lancement de Windows 11 26H2 est imminent. Microsoft n’a toujours pas communiqué de date officielle pour le grand public cependant les premiers fichiers servant à construire les supports d’installation de cette nouvelle version viennent d’apparaître.

Les fichiers ESD associés à Windows 11 26H2 Build 26300.9457 ont été repérés sur les serveurs de Microsoft. Il s’agit d’une étape importante dans la préparation du déploiement d’une nouvelle version de Windows.

Windows 11 26H2 se prépare pour le déploiement

Ces fichiers utilisent le format ESD, pour Electronic Software Distribution. Microsoft utilise ce format compressé pour distribuer les images de Windows et produire différents supports d’installation. Cela concerne par exemple le notamment ceux exploités par le service Windows Update, les fichiers ISO et l’utilitaire Media Creation Tool.

Les fichiers en question font référence à Windows 11 26H2 Build 26300.9457.

Selon un rapport ces ESD sont actuellement distribués sur des serveurs internes de Microsoft. Pour rappelle, lors de précédentes sorties de Windows 11, leur apparition est généralement intervenue peu avant le début du déploiement Grand Public.

26H2 est déjà sur le canal Release Preview

Cette découverte n’est pas vraiment surprenante car Microsoft a envoyé Windows 11 26H2 sur le canal Release Preview du programme Windows Insider dès le 27 août dernier.  La première version était la Build 26300.9278. Microsoft expliquait alors officiellement que Windows 11 26H2 était distribué sous la forme d’un package d’activation, ou eKB.

Le passage par Release Preview constitue l’une des dernières étapes avant une diffusion à plus grande échelle.  Le catalogue Microsoft Update contient par ailleurs déjà différentes mises à jour destinées à Windows 11 26H2, notamment KB5124008 (Build 26300.9445), KB5129195(Build 26300.9457) et KB5124010 (Build 26300.9550).

Windows 11 26H2, une  une mise à jour légère…

Windows 11 26H2 n’annonce aucun changement de plateforme comparable au passage vers Windows 11 24H2. Microsoft utilise cette fois un mécanisme d’enablement package.

Comme GinjFo l’a expliqué dans cette actualité Windows 11 26H2 approche mais n’attendez pas de révolution le principe consiste à livrer progressivement le code commun au travers des mises à jour mensuelles puis à utiliser un petit package pour activer la nouvelle version lorsque celle-ci est prête.

Pour un PC déjà à jour et compatible, le passage à 26H2 va se résumer à une mise à jour cumulative et non à une réinstallation complète de Windows. Un des avantages de cette approche est de réduire les perturbations et les risques de compatibilité associés aux migrations vers une nouvelle plateforme.

Enfin soulignons que le changement le plus visible sera le numéro de build. Windows 11 25H2 repose sur la branche 26200 tandis que Windows 11 26H2 passe à la branche 26300.
