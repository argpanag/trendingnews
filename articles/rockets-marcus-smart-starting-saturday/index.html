Rockets' Marcus Smart: Starting Saturday

TheTools · 01.11.2026 02:01 · source · permalink

Smart will start Saturday against the Thunder, Will Guillory of The Athletic reports.

Smart is getting the start with both Fred VanVleet (rest) and Reed Sheppard (back) out, and he'll be joined in the first unit by Amen Thompson, Kevin Durant, Jabari Smith and Alperen Sengun. Per 36 minutes this season, Smart is averaging 12.7 points, 3.9 assists, 1.1 triples and 2.8 steals per game.
