Votre sauvegarde automatique Windows est en panne ?

TheTools · 28.09.2026 16:55 · source · permalink

Suite à l'installation des mises à jour de sécurité de septembre 2026, des utilisateurs ont constaté que l'outil de sauvegarde automatique de Windows, l'Historique des fichiers, cessait de fonctionner.

Le problème se manifestait par des plantages enregistrés dans l'Observateur d'événements avec des références à FileHistory.exe et Kernelbase.dll. Bien que remplacée par Windows Backup, la fonctionnalité reste un outil encore central pour certains.

Quels étaient les symptômes ?

Les utilisateurs touchés par le bug recevaient des alertes trompeuses, comme des demandes de reconnecter un lecteur, même lorsque leur disque de sauvegarde externe ou leur emplacement réseau était fonctionnel.

En essayant de restaurer un fichier, ils pouvaient également se heurter à un message indiquant " Aucune version antérieure disponible ", rendant la fonctionnalité totalement inopérante.

Le bug a été confirmé par Microsoft pour les versions les plus récentes et antérieures de Windows 11, ainsi que Windows 10.

Un problème résolu par Microsoft

Le problème a été discrètement corrigé dans les mises à jour pour le moment optionnelles (preview) de Windows 11, dont la mise à jour KB5124010 pour Windows 11 version  25H2 et 24H2.

" Cette mise à jour corrige un problème empêchant la sauvegarde ou la restauration de fichiers via l'Historique des fichiers sur un disque externe ou un emplacement réseau ", écrit Microsoft.

Les utilisateurs impatients peuvent installer la mise à jour optionnelle en se rendant dans Windows Update et en lançant une recherche manuelle. Sinon, le correctif sera inclus dans le prochain Patch Tuesday prévu pour le 13 octobre, sachant que la mise à jour KB5124010 (preview) souffre elle-même de ratés.
