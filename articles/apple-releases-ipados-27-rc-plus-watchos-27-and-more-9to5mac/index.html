Today following its “Surprise and shine” September event, Apple has shipped the RC (release candidate) versions of iPadOS 27, watchOS 27, and more.

RC versions of iPadOS 27 and more available now for testing

Apple’s major new software updates for iPhone, iPad, Mac, and more are almost here.

iOS 27, iPadOS 27, macOS Golden Gate, watchOS 27, tvOS 27, and visionOS 27 will ship to all users next week on Monday, September 14.

After a full summer of beta testing, today Apple is rolling out the RC versions of those updates.

Developers and public beta testers can install the RC for iPadOS 27 and more via the Software Update screen in Settings.

Release candidate builds are intended to be the final shipping software that launches to all users. But if Apple discovers any critical issues that need to be patched, we may see RC 2 builds debut soon.

It’s become common practice for Apple to ship the RC builds of its major new software updates right after the annual iPhone launch event.

That’s because there are often new features not announced at WWDC that remain hidden until the September event. For example, today Apple detailed watchOS 27 changes during the Apple Watch hardware unveiling that were not mentioned in June—but are now available in the watchOS 27 RC.
