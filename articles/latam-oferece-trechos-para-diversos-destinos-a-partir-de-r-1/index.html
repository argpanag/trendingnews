Desconto na modalidade pontos + dinheiro

Além disso, você pode realizar a transferência utilizando a modalidade pontos + dinheiro, onde é possível gerar um CPM [custo para cada mil pontos] mais atrativo. Utilizando a ferramenta, é possível gerar 1.000 milhas no programa aéreo a partir de R$ 23,58, o que é bem interessante! Confira:

Acompanhe o nosso cálculo para uma transferência de 100.000 pontos para o LATAM para os assinantes ativos do Clube LATAM Pass:

  • 1.000 pontos (CPM vigente para o Turbo Livelo): R$ 32
  • 99.000 pontos x R$ 29,45 (valor vigente nas transferências para o LATAM Pass na modalidade pontos + dinheiro, pagando com Pix): R$ 2.915,55
  • Total: R$ 2.947,55
  • CPM [custo para cada mil pontos]: R$ 29,47

Ou seja, você comprará 100.000 pontos Livelo a um custo para cada mil pontos de R$ 29,47, os quais serão transformados em 125.000 pontos no LATAM Pass, considerando 25% de bônus. Deste modo, o CPM no LATAM Pass será o seguinte:

  • 100.000 pontos Livelo = R$ 2.947,55
  • Quantidade de milhas recebida no LATAM Pass: 125.000
  • CPM no LATAM Pass: R$ 23,58

Para pagamentos no cartão de crédito com parcelamento, usando o mesmo raciocínio, chegamos no valor de CPM LATAM Pass de R$ 24,80.

Custo efetivo da emissão

Assim, descoberto o valor do CPM [custo para cada mil milhas] no LATAM Pass, vamos ao valor efetivo da emissão:

  • Quantidade de milhas para o trecho: 125.588
  • CPM: R$ 23,58
  • Valor em dinheiro: 126 (Valor arredondado da emissão) x R$ 23,58 = R$ 2.971,08 + taxas

Caso você possua milhas LATAM Pass orgânicas tenha em mente que, neste caso, o valor da passagem poderá sair ainda mais barato!
