Modders Unlock DLSS Multi Frame Generation For RTX 30-Series "Ampere" GPUs

TheTools · 10.09.2026 08:52 · source · permalink

Wednesday, September 9th 2026 Modders Unlock DLSS Multi Frame Generation For RTX 30-Series "Ampere" GPUs After porting DLSS 5 to every recent NVIDIA generation, the modding community now seems to be turning its focus to Frame Generation. A new mod called DLSSG SM86 lets GeForce RTX 30-series owners run DLSS Multi Frame Generation in 2X and 4X modes, a feature NVIDIA officially reserves for RTX 50-series "Blackwell" GPUs. Unlike earlier workarounds that swap in AMD's FSR Frame Generation, this project keeps NVIDIA's own DLSS models intact. It works by creating a proxy backend for the RTX 30-series' SM86 architecture that runs alongside the game and redirects frame generation calls to a bundled DLSSG 310.1 runtime, without touching the game's own files. The developer's documentation lists the RTX 3080 Ti as the tested card, running driver 591.86 under Windows with D3D12. Reported gains include Black Myth: Wukong climbing from 50 FPS to 150 FPS at 4X Frame Gen, and Cyberpunk 2077 with path tracing going from 35 FPS to 100 FPS. That said, the developer is upfront that formal frametime, latency, and long-duration stability testing hasn't been done yet, so real-world smoothness don't fully match those raw numbers. A YouTube video by fogoticus also shows the feature being tested on an RTX 3080, with Cyberpunk 2077 jumping from around 42 FPS to 74 FPS in 2X mode, then to 120 FPS in 4X mode. As to why this wasn't previously available, NVIDIA has pointed to Blackwell's Flip Metering as the reason Multi Frame Generation stays exclusive to RTX 50-series cards, since it keeps frame pacing steady. Modders have already found ways to run the leaked DLSS 5 build on older Ampere hardware, with mixed results. It seems that the modding community is intent on proving that NVIDIA's generational walls aren't completely explained by hardware limits. Sources: DLSSG for SM86 (GitHub), fogoticus on YouTube, Reddit
