Windows 11 just made testing your internet speed easier

TheTools · 08.10.2026 21:14 · source · permalink

When you purchase through links in our articles, we may earn a small commission. This doesn't affect our editorial independence.

Want to know how fast your internet really is? Windows 11 now lets you check right from your taskbar.

Since the end of February 2026, Microsoft has been distributing a new internet speed test via Windows Update. You can find it by right-clicking the network or Wi-Fi icon in the bottom-right corner of the taskbar. The option Perform Speed Test now appears in the menu.

Clicking on this opens your browser and takes you to a page on Microsoft’s Bing search engine. This browser-based test uses Ookla’s Speedtest. Ookla is the unofficial global market leader in internet speed tests. The option in the network icon’s context menu is simply a link, but it makes it easier to run the Ookla test.

To start the test, click on Start. The test will first determine the ping from your computer to a Telekom server, and then it will start measuring download and upload speeds. As an alternative to the Bing test, you can also use the Ookla test directly.

You can find the browser version at www.speedtest.net or you can download it from the Microsoft Store as a standalone app.
