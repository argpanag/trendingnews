Elokuvat | Kymmenen faktaa, joita ei kerrota You Can See Everything -hittidokumentissa

TheTools · 28.11.2026 10:01 · source · permalink

Elizabeth Holmes dokumentissa You Can See Everything.

Katsojia villinnyt dokumentti You Can See Everything on saanut aikaan keskusteluja totuudesta. Haimme vastaukset kysymyksiin, jotka jäävät elokuvassa auki.

You Can See Everything hämmentää monia katsojaryhmiä.

Katsojaennätyksiä tehnyt dokumentti ei keskity Elizabeth Holmesin rikoksiin vaan käsittelee eri keinoin sitä, puhuuko entinen veriyrittäjä koskaan totta.

Samalla se saa miettimään, voiko dokumentti ylipäätään välittää jonkinlaista objektiivista totuutta. Kaikkea ei todellakaan nähdä, vaikka vitsikäs nimi niin lupaa.
