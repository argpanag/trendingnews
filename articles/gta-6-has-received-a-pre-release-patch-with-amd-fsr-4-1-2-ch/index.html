GTA 6 has received a pre-release patch with AMD FSR 4.1.2 changes for Xbox Series X and S.

TheTools · 18.11.2026 12:48 · source · permalink

Two days before the official release of Grand Theft Auto 6, Rockstar Games uploaded the latest pre-release build to the Xbox servers. According to a dedicated update tracker, which had previously accurately recorded the release of the previous patch, the new fix directly affects system image scaling components on Microsoft consoles. The list of modified files includes the dynamic library amd_fidelityfx_upscaler_xbox.dll, which is responsible for AMD's upscaling algorithms.

The system file in question is directly linked to the new AMD FSR 4.1.2 scaling technology, which Microsoft recently integrated into the Xbox Game Development Kit for the current-generation Xbox Series X and Xbox Series S consoles. Data miners had previously found loader and upscaler libraries for this version in the game distribution while analyzing preload files, but their presence in the code alone did not guarantee that the technology would work on release day.

A fresh patch with a modified scaling library is already available on Microsoft's servers, but remains unavailable for download for regular users. Insider eXtas1s emphasizes that the mere fact of modifying the amd_fidelityfx_upscaler_xbox.dll file just before the release date does not automatically activate the FSR 4.1 algorithm in the final version. However, the fact that this component was modified just before the release of Grand Theft Auto 6, scheduled for November 19, 2026, indicates that Rockstar Games engineers are actively working to optimize upscaling for Xbox consoles.
