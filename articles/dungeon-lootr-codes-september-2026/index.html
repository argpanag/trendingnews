How to redeem Dungeon Lootr codes

There are two different ways you can redeem codes in Dungeon Lootr. Whichever way you choose, the first thing you need to do is join the developer's Roblox group. You won't be able to redeem codes without doing this. You will then need to launch Dungeon Lootr in Roblox.

Redeem codes in a dungeon

  1. When you're in a dungeon, select the 'Menu' button and then choose 'Settings'.
  2. In the next menu choose the 'Codes' option.
  3. Type a code into the text box and then press the 'Claim' button.

Redeem codes in the lobby

  1. When you're in the lobby, select the 'Menu' button on the left, followed by the 'More' option.
  2. In the next screen choose the 'Codes' option.
  3. Type a code into the text box and then hit 'Claim'.
