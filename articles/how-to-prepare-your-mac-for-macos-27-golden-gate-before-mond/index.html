How to Prepare Your Mac for macOS 27 Golden Gate Before Monday

TheTools · 13.09.2026 14:28 · source · permalink

macOS 27 Golden Gate ships as a free update Monday, September 14, and Apple’s own support pages describe three concrete steps a Mac owner can take before then: confirm the Mac qualifies, clear enough storage for the download, and back up first. None of it requires anything beyond System Settings and, ideally, an external drive.

Key facts

First, confirm the Mac actually qualifies

Apple’s compatibility list for macOS 27 names MacBook Neo (2026), MacBook Air and MacBook Pro with Apple silicon from 2020 on, iMac with Apple silicon from 2021 on, Mac mini with Apple silicon from 2020 on, Mac Studio from 2022 on, and the 2023 Apple silicon Mac Pro. No Intel Mac appears on that list. Checking is a 10-second job: Apple menu, About This Mac, which shows the exact chip and year.

  • Apple menu (top left) then About This Mac
  • Note the chip name and, for a MacBook Air or Pro, the year of the specific model
  • Compare that against Apple’s published macOS 27 compatibility list before assuming an update is coming

Then clear space, using Apple’s own storage tools

Apple’s storage-management support page recommends turning on the built-in optimization feature so a Mac can “automatically make more storage space available when needed,” clearing the Downloads and Trash folders, removing unused apps and old device backups, and moving large photo and video libraries off the internal drive. Apple also notes that starting a Mac in safe mode can temporarily free additional space specifically for a task like installing a macOS update, though that space is not permanent.

Back up with Time Machine before you install

Apple’s Time Machine support page lays out the setup in one path: System Settings, General, Time Machine, Add Backup Disk, then choose an external drive at least twice the size of the Mac’s own storage. Once set up, “Back Up Now” in the Time Machine menu runs an immediate backup, and Apple’s own description of the schedule is specific: hourly backups for the past 24 hours, daily backups for the past month, and weekly backups for everything older than that. A backup made the night before a major OS update is the cheapest insurance available, and it is built into every Mac already.

Installing on the day

Apple describes Software Update, found in System Settings under General, as “the fastest and easiest way to get macOS updates and upgrades,” and says it can use less storage than downloading the same release through the App Store. For anyone also updating an iPhone the same day, the iOS 27 release date article and the event recap cover what changes on the phone side, and Apple has stated the same September 14 date across iOS 27, iPadOS 27, macOS 27, watchOS 27 and visionOS 27.

What Apple has not said

Apple’s own update and storage support articles do not state exactly how much free space macOS 27 needs, and do not explicitly instruct users to back up before a major update inside the update article itself, even though the tools to do so sit one menu away. Apple also has not published an estimated install time for macOS 27 specifically.

The safest order is compatibility check, storage cleanup, backup, then Software Update, ideally finished before Monday morning so the new build is ready rather than mid-download when the workday starts. Anyone weighing new hardware instead of an update on an older Mac can compare against what ships on September 22 before deciding.
