Samsung officially releases One UI 9 for the Galaxy S26, S26+, and S26 Ultra

TheTools · 17.09.2026 01:17 · source · permalink

Login

Vlad 16 September 2026

Samsung Android Firmware Updates

Following a months-long beta testing period, today Samsung is finally releasing the stable version of One UI 9 based on Android 17 for the Galaxy S26, S26+, and S26 Ultra. The update will start rolling out in various markets, and it seems like Samsung's home country of South Korea got it first as a 650ish MB over-the-air download.

Samsung highlights My FanCam as one of the key new features in One UI 9. You can see this in action below.

You can also create and edit your own cards for the Now Brief using generative AI, as shown in the video below.

Now Nudge has been improved too, as seen below. The company claims there are fewer steps now.

Samsung says you can expect to see a better Creative Studio, Interpreter, Document Scan, and Voice recorder too. Additionally, there's the new Warranty and Care settings menu which was detailed back in August.
