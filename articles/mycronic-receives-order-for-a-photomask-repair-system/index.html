Mycronic receives order for a photomask repair system

TheTools · 25.11.2026 22:17 · source · permalink

Mycronic AB (publ) has received an order for a display photomask repair system from an existing customer in Asia. The order value is in the range of USD 4-5 million. Delivery of the system is planned for the second quarter of 2027.

Laser-based photomask repair systems, developed and manufactured by Cowin DST in South Korea, repair defects identified during inspection, after photomasks have been exposed in a mask writer and processed. This improves yield in the photomask manufacturing process. Mycronic provides photomask repair systems for both the semiconductor and display industries.

“This order for a photomask repair system in an extensive configuration for the display industry, includes some development and demonstrates how Cowin DST broadens Pattern Generators’ offering within our existing customer base. Looking ahead, we see further opportunities to deliver efficiency gains through more holistic solutions”, says Mikael Wahlsten, Sr VP Pattern Generators at Mycronic.

Mycronic’s Pattern Generators division provides mask writers and metrology, inspection and repair systems for display manufacturing and production of semiconductors.
