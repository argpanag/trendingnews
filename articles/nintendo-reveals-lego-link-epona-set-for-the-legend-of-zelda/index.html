Nintendo Reveals Lego Link & Epona Set for The Legend of Zelda 40th Anniversary

TheTools · 08.09.2026 14:19 · source · permalink

Nintendo has revealed an Ocarina of Time-themed Lego Link & Epona set as part of its The Legend of Zelda 40th Anniversary Direct.

The set was unveiled along with a series of other events, merchandise, and more that the company is set to roll out through the rest of 2026 and part of 2027. It’s unclear when exactly the Lego Link and Epona set will join other previously released sets for the series with an official launch.

You can see a first look at the Lego Link and Epona set below.

Nintendo revealed additional details about its new The Legend of Zelda Legos in a press release following today's Direct. It confirmed The Legend of Zelda: Ocarina of Time – Link & Epona is a 1,750-piece set and described it as a "collectible display model for adults." It is expected to launch spring 2027.
