Windows 11’s big redesign has started shipping, and the first thing it kills is the Windows 8-era pop-up that asks what to do every time you plug in your phone

TheTools · 14.11.2026 19:24 · source · permalink
  • Windows 11

In March 2026, Microsoft announced plans to modernize Windows 11 and make the UI more consistent. Most of us would have dismissed it as another empty promise, as it’s not the first time the company has declared it would get things right. But eight months later, Microsoft’s modernization efforts are no longer just talk.

The first phase of Windows 11’s big redesign is finally shipping, and the first feature is AutoPlay. The November 2026 update is replacing the Windows 8-era pop-up that asks what to do every time you plug in your phone, and it makes the experience far more useful.

Unlike past redesigns, Windows 11 is not getting a major facelift in a single annual release. Instead, Microsoft plans to slowly replace legacy dialogs, including those from the Windows XP era, with modern versions. It’s a slow and painful approach, but Microsoft has opted for this route because it doesn’t want to upset consumers with half-baked replacements and wants to use feedback wisely.

I can confirm that this month’s mandatory security update (KB5132061), which bumps Windows 11 26H2 to Build 26300.9974 and 25H2 to Build 26200.9974, includes the new AutoPlay. However, it’s rolling out gradually, so you might not see it immediately after installing the update.

If you often connect a USB drive, an SD card from your digital camera, or a mobile device, you’ve probably seen a pop-up in the top-right corner of your desktop. That dialog is called AutoPlay, and it pops up when Windows wants you to decide what to do with the connected device.

If you don’t recall, here’s what the old AutoPlay dialog looks like when you connect your mobile device via USB:

It asks you to choose what you’d like to do with the device, and the five options in the screenshot should be familiar if you frequently connect drives or devices to your computer. The first option is to import photos or videos to local storage, while the second option does the same thing but to your OneDrive.

You also have the option to sync digital media files to the device using Windows Media Player. You can choose to “Open device to view files,” which opens File Explorer. And the last option is basically dismiss, aka take no action.

Here’s the new AutoPlay dialog for comparison:

Microsoft hasn’t touched AutoPlay in years, but as we reported previously, the company also plans to move more Control Panel features to Settings.

AutoPlay is not a new idea, as the feature has been around since the early days of Windows XP, but its purpose has evolved over time. In 2001, you’d use AutoPlay for a disc or drive instead of your mobile device. Later, it was updated with Windows Vista with better security, but the overall functionality largely remained unchanged.

The new AutoPlay can remember what you want to do

This modern AutoPlay is a good example of how Microsoft can modernize Windows without dumbing things down. In fact, it’s better than the version we’ve had since the Windows 8 era.

First, the modern AutoPlay is centered, so it doesn’t appear in the top-right corner of the screen, which never made sense to begin with. It also supports dark mode, has rounded corners, and feels in line with Windows 11’s overall design guidelines. And most importantly, you’ve got an option to make AutoPlay remember your preference directly from the dialog.

That means if you connect your phone, choose the option to open File Explorer, and select “Always,” you won’t be asked again the next time you connect your phone. File Explorer will automatically open as soon as you connect your mobile device!

It’s worth noting that the old dialog doesn’t have “Always” or “Just once” buttons, although you could already change AutoPlay defaults from Settings > Bluetooth & devices > AutoPlay. Now, you can make that choice right from the pop-up.

In our tests, Windows Latest also observed that new AutoPlay notifications now stay in Notification Center, and I think it’s a great addition. For example, if you accidentally miss the notification, you can now open Notification Center and view it. It’s better than reconnecting your phone just to bring it back.

Microsoft plans to replace the Windows Run dialog next, but it’ll let you decide

After the AutoPlay dialog, Microsoft plans to replace Windows Run with a modern version, and it’s expected to begin rolling out to regular PCs with this month’s optional update. If you choose to enable modern Run from Settings, you’ll get the dialog below instead of the current legacy one:

As we reported recently, the optional update is scheduled to arrive in the last week of November. The modern Run should then ship with the mandatory Patch Tuesday update on December 8, although it’s rolling out gradually.

Unlike AutoPlay, the modern Run dialog will be optional for now. Once it reaches your PC, you can turn it on from Settings > System > Advanced. Since it’s optional, it doesn’t fully replace the legacy version, so you can turn the toggle off and bring it back.

In our tests, Windows Latest observed that modern Windows Run follows a Fluent Design approach, is minimalist in design, supports dark mode, and shows your recent commands.

You’re not losing anything with modern Run, except for the old “Browse” button. According to Microsoft, it did not make sense to keep the button we have in the existing Run dialog because only 0.0038% of users in a sample of 35 million had clicked it.

It’s also worth noting that modern Run is not slow, so you don’t have to worry about the performance concerns that usually come with WinUI modernization efforts. I think we’re past that at this point, as Microsoft has already confirmed that performance is one of the top priorities for WinUI.

This explains why the new WinUI Run opens in a median of 94 milliseconds, compared to 103 milliseconds for the legacy version. Of course, it’s not a difference most of us would notice, but I’m glad the modern version isn’t slower.

File Explorer’s Properties dialog is getting a redesign, too

The next big Windows 11 design refresh is for the Properties dialog in File Explorer. This was previously spotted in Windows Insider builds, and we expect it to begin rolling out to the public in early 2027.

Right now, if you right-click a file or folder and select “Properties,” you’ll still see a dialog based on the Windows 95-era design. Microsoft is rebuilding it in WinUI, and the new version finally supports dark mode.

The modern Properties dialog isn’t just a fresh coat of paint, as it’s built from scratch using WinUI 3. Microsoft also needs to make sure the redesign doesn’t break backward compatibility.

There are still plenty of old dialogs waiting for the same treatment, but after months of promises, it’s good to see some of these changes finally reach our PCs!
