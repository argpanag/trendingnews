Fabio akui Java United kesulitan bongkar lini pertahanan Isenmulang - ANTARA News Ambon, Maluku

TheTools · 21.10.2026 15:03 · source · permalink

Jakarta (ANTARA) - Pelatih Java United Fabio Lefundes mengakui tim asuhannya kesulitan membongkar lini pertahanan Isenmulang FC dalam laga Super League di Stadion Maguwoharjo, Sleman, Selasa sore.

"Kami sudah mengetahui bahwa lawan akan bermain dengan pertahanan rapat untuk meraih hasil. Permainan seperti itu akan semakin menyulitkan saat mendekati akhir laga," kata Lefundes seperti dikutip laman I.League pada Selasa.

Java United harus puas pulang dengan satu poin setelah imbang 1-1 di kandang Isenmulang.

Isenmulang unggul lebih dahulu melalui Kenji Nishioka pada menit ke-59, yang delapan menit kemudian disamakan Gustavo Almeida.

Keputusan Lefundes mengganti pemain berbuah gol Gustavo walau harus menunggu tinjauan VAR.

"Kami merespons pendekatan lawan dengan melakukan perubahan strategi dan pemain," kata Lefundes.

Java United naik ke peringkat ke-10 klasemen Super League dengan enam poin dari enam laga, sedangkan Isenmulang ke posisi ke-16 dengan dua poin.
