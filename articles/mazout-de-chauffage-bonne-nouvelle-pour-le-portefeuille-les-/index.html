Mazout de chauffage : bonne nouvelle pour le portefeuille, les prix maxima baissent mercredi

TheTools · 22.09.2026 14:32 · source · permalink

Les prix maxima du gasoil diesel (application chauffage) et du gasoil de chauffage diminueront à partir de mercredi, a annoncé mardi le SPF Économie.

Pour une commande de moins de 2.000 litres de gasoil diesel (application chauffage), le prix maximum baisse de 8,76 centimes, à 1,5341 euro le litre. A partir de 2.000 litres, le prix maximum s’établira à 1,4936 euro le litre (-8,76 centimes également).

Pour le gasoil de chauffage (H0/H7), les nouveaux prix maxima sont fixés à 1,5102 euro le litre (-0,0875 euro) pour moins de 2.000 litres et à 1,4697 euro le litre (-0,0874 euro) à partir de 2.000 litres.
