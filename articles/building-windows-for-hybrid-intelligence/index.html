Building Windows for hybrid intelligence

TheTools · 07.10.2026 18:00 · source · permalink
  • Pavan Davuluri, Executive Vice President, Windows + Devices

Agents are creating a foundational shift in how people get things done, unlocking new levels of productivity and capability on the PC. As agents become part of everyday work, they also raise the bar for compute, security, and control.  

That’s why we’re building Windows as the home for hybrid intelligence: a platform where agents can run locally when it makes sense, reach the cloud when they need to, and operate with the security and manageability organizations expect. 

Hybrid intelligence expands what’s possible. Windows makes it practical, secure, and ready for broad adoption. And powerful new silicon, devices and models unlock local compute. Together, they define the next chapter of the PC: 

  • Windows is the most secure platform for agents. With containment, identity, and manageability built into the platform, Windows helps you control what agents can access, know which agent acted, and govern them at scale. Microsoft Execution Containers (MXC), now generally available for Windows and integration with Microsoft Agent 365, are key steps in making that real.   
  • Hybrid intelligence brings frontier capability to Windows locally. With intelligent routing, powerful local models, and a performant runtime, Windows lets work run in the right place for each task — local or cloud. We’re bringing frontier-class capabilities to local PCs and enabling services like GitHub to route intelligently on Windows. 
  • Copilot gets supercharged with Windows hybrid intelligence. With your permission, Copilot will be able to use local context from your PC, take action on your behalf, and tap into local models, bringing you more capability while helping your tokens go further. 
  • A new generation of PCs built for these possibilities. From always-on mini desktop PCs to deskside supercomputers powered by DGX Station for Windows, we are bringing a broad range of devices to unlock hybrid intelligence. Surface Laptop Ultra, powered by NVIDIA RTX Spark™, is available for pre-order today, alongside new devices from ASUS, Dell, HP, Lenovo, and MSI. 
  • Windows gets more capable across everyday tasks including new ways to take action directly from Windows Search on the taskbar and enhancements in gaming. 

Windows is the most secure platform for agents

Agents don’t work like traditional apps. They can run around the clock, use tools, write code, access files, and act across systems, often without someone watching every step. That requires a new security model built for how agents actually operate.

On Windows, that model comes together through containment, identity, and manageability. Containment controls what an agent can access. Identity makes clear which agent acted, so IT can distinguish agent activity from the person using the device. And manageability connects that activity into tools like Agent 365 and Intune, so organizations can set policy, monitor risk, and govern agents across the organization1. 

Together, these primitives allow organizations to secure, observe, and govern agents with confidence.

Expanding the ecosystem of agents on Microsoft Execution Containers, now generally available

Traditional sandbox solutions weren’t designed for agents, where containment needs can change with every prompt and tool call. We built Microsoft Execution Containers (MXC) to meet that need.

Today, Microsoft Execution Containers (MXC), becomes generally available on Windows 11, enabling organizations to define which files and networks agents can access, with those policies enforced at runtime. For individuals using AI on their personal PC2, these safeguards are part of the agent experience itself, giving users a more secure way to work with these tools.

While MXC works across operating systems, its deep integration with Windows gives organizations more control of their data and a broader range of containment options, from process and session isolation to WSLc, virtual machines, and Windows 365 for Agents.

Leading agents already support MXC, including Codex from OpenAI, GitHub Copilot, OpenClaw, Replit, LM Studio, OpenShell from NVIDIA, and Unsloth AI. Many others will be releasing support for MXC: Anthropic Claude Code, Box, Egnyte, Heidi Health, Hermes Agent by Nous Research, Manus, Perplexity, Raycast, and Simular amongst others.

We’re also excited to share that Muse for Windows, a personal AI agent from Meta, is coming soon as a native app on Windows with MXC integration, bringing another leading AI experience to Windows and providing more choice in the agents people can use on their Windows PC.

To learn more about how developers can integrate their agents with MXC, visit: Microsoft Execution Containers: Policy-driven containment for AI agents. 

Bringing hybrid intelligence to Windows

As AI models grow in size and capability, customers’ needs are outpacing what their cloud budgets can support. They want to make every AI token count without giving up frontier capabilities. Hybrid intelligence brings local and cloud AI together, helping customers stretch their budgets while preserving access to the intelligence they need.  

To bring this to life requires powerful local models, intelligent orchestration, a performant runtime, and capable silicon, all working together to create a meaningful experience.

Frontier coding intelligence, running locally on your PC

At Build, we introduced MAI Code 1.1 Flash, a 137 billion total and 6.8 billion active parameters, designed for real-world coding workloads. Today, we’re bringing that intelligence to your device, using 3-bit precision to reduce the model size by nearly 80% while preserving coding quality and supporting a 256K context window locally. 

In addition to MAI Code 1.1 Flash, we are bringing other powerful models like an upcoming Nemotron model from NVIDIA – with over 70 billion parameter and quantized in 2-bit to use just over 20GB of memory and DeepSeek V4 Flash, a 284B parameter model, and others for optimal speed and intelligence running locally on RTX Spark. 

With optimization and tuning, these models bring what was frontier-class capabilities to local PCs while preserving accuracy and performance — using less memory and fewer system resources. 

The goal is to keep AI responsive while leaving room for everything else you do on your PC.

Introducing intelligent routing on Windows with GitHub HydraFusion

Earlier this year, GitHub launched HydraFusion, which routes each task to the right model in the cloud.  

Today, we’re extending that intelligence to Windows, enabling HydraFusion to tap into models running locally on device, making your tokens go further.  

Hybrid intelligence on Windows, powered by HydraFusion is coming to the GitHub Copilot app, GitHub Copilot CLI and Visual Studio Code in experimental preview later in October.  

To learn more about how we’re working with GitHub to make this possible on Windows, read: Bringing local models and sandboxed tools to Windows and GitHub Copilot. 

Bringing llama.cpp to Windows ML to provide easier access to open-source models

To power this growing ecosystem of highly capable local models, you need a performant runtime. Windows ML is a scalable runtime to deploy models across GPU, NPU, and CPU, and we’re continuously evolving it.  

Today, we’re also announcing llama.cpp support in Windows ML, giving developers more open-source model choices, and the ability to experiment quickly with emerging models as they land. 

To learn more, visit AI Development on Windows: from PyTorch and llama.cpp to Windows ML. 

Supercharging Copilot on Windows with hybrid intelligence

Recently, we introduced the new Copilot built around three experiences: Home, Code, and Autopilot. Today, we’re announcing that on Copilot+ PCs, Copilot will get supercharged with Windows hybrid intelligence, providing three key local capabilities.   

  • Local context. With your permission, Copilot can understand relevant content on your PC, including files and recent activity, bringing local context into the flow of work. 
  • Local actions. Copilot can take action on your behalf across Windows, helping complete tasks like organizing files, assessing device diagnostics, troubleshooting issues, coding, and carrying out workflows directly on your device. 
  • Local models. Copilot can tap into AI models running on your PC, using local compute for the right tasks while combining it with cloud intelligence when needed. 

Across Home, Code, and Autopilot, hybrid intelligence makes Copilot more useful on Windows. 

In Home, Copilot can use local context from your PC to pull in the files you’ve been working on and help turn them into collaboration-ready artifacts. 

In Code, hybrid intelligence helps you create native Windows apps from a single prompt, run code more securely with MXC support, and use local models when appropriate so projects can move faster and token costs can be managed. 

And hybrid intelligence will make Autopilot, a persistent, proactive and personal agent, even better. Hybrid intelligence brings local context, local models and PC actions into the agent flow, enabling more grounded personal agent experiences that can continue working on your behalf, even while you focus on other things. 

This is the next step for Copilot on Windows, powered by hybrid intelligence. Copilot understands your PC, takes action with your permission, and uses local models when it makes sense, with you in control at every step. Copilot features powered by hybrid intelligence are expected to begin rolling out on Copilot+ PCs in the coming months.3

Offering a range of PCs for agentic work

To bring our vision of hybrid intelligence and new experiences to every desk and every home, you need a broad range of silicon and Windows PCs, from mini desktops up to deskside supercomputers.

Mini desktop PCs, with a simplified out-of-box setup for running agents 

People are already using mini desktop PCs as always-on machines for long-running agents. But too often, getting started requires terminal-based setup, complicated configuration, and security trade-offs that weren’t designed for agent workloads. 

Today, we’re announcing a simpler way to set up popular agents on mini desktop PCs in just a few clicks, right out of the box. For OpenClaw users, we’re introducing a native Windows gateway that simplifies setup, along with MXC integration to help keep agents securely contained in a sandbox. 

This is just the beginning. Over time, we intend to bring these experiences to more Windows devices, guided by customer feedback, so more people can securely run and work with the agents they choose.

With fast performance, great battery life, and built-in AI features, Copilot+ PCs are your PC for everyday tasks, with even more capability on the way with the new Copilot and hybrid intelligence.

This unlocks the power to run frontier-class models locally, from Llama 4 Maverick and Kimi K2.6 to DeepSeek V4 Pro, at more than a trillion parameters9.

Capabilities that once required renting a cluster, now in a deskside supercomputer. This brings a new level of AI compute to Windows, enabling developers, engineers, scientists and organizations everywhere to run frontier-class models and agentic workloads on devices that were previously limited to the cloud or data centers. The DGX Station for Windows enables 2 key customer scenarios:

  • Personal AI Supercomputer: For the most demanding engineering, scientific, and research workloads, DGX Station for Windows enables a generation of powerful Windows applications accelerated by multimodal agents that can model, perceive, and design for the physical world.

The result is a shared AI resource on Windows that helps lower operating costs, improve responsiveness, and give teams greater control over how and where their AI workloads run. Paired with MXC, it’s never been easier to build, govern, secure, and trust end-to-end agentic loops on Windows.

Windows gets more capable across everyday tasks

Hybrid intelligence opens up an entirely new chapter for Windows, but innovation isn’t only about what’s next. It’s also about making the experiences you rely on every day faster, easier and better, from getting things done to how you play. 

Introducing actions in Windows Search: Go from finding to doing

Search has always been about quickly helping you find what you need. Today, we’re introducing a new Windows Search experience that is faster, more efficient, and enables richer experiences, beginning with thousands of new actions that will be available directly from the taskbar. 

These new actions help you finish tasks right where you started, without opening another app or navigating through additional screens. We’re starting with familiar tasks where saving a few steps can make a meaningful difference in everyday use.   

Here are a few things to try:  

  • Turn something on or off. Try phrases such as “switch to dark mode, “turn on Do Not Disturb,” or “enable Airplane mode.” 
  • Make a quick adjustment. Try “dim my screen” or “mute.”
  • Manage your workspace. Try “minimize all my windows,” or “arrange my windows.”
  • Send a message. Try “Text Elisa I’ll be there soon.” 

We will also begin adding the option to integrate the new Copilot with Search on the taskbar, so you can get quick answers inline from Search, and if you want to have a richer conversation, you can jump from Search directly to the full Copilot app. This experience will be opt-in, and will first start rolling out to select markets later this year.

New actions will begin rolling out to Windows Insiders in the experimental channel today. Visit to read more: From searching to doing: Building a faster, more streamlined Windows Search . 

Advancing gaming across the Windows PC ecosystem

Gaming is a fundamental part of Windows, and with new Windows PCs powered by RTX Spark, we’re continuing to expand where and how people can play the games they love. 

Over the past several years, we’ve made significant investments to improve the gaming experience on Arm-based Windows PCs with expanded availability of Prism, support from leading anti-cheat providers, and XBOX PC app compatibility.  

RTX Spark™ now raises those investments to new levels for gaming performance and graphics capabilities, showcased by Gears of War: E-Day, with support for features like DirectX raytracing, variable rate shading, and DirectStorage. Gears will also be the first to offer expanded support for Advanced Shader Delivery, cutting first-launch shader compilation from minutes to seconds and helping reduce in-game stutter, so players spend less time waiting, and more time playing. 

Combined with growing support from game developers and publishers such as Electronic Arts, Embark, Tencent and Ubisoft joining KRAFTON, NetEase, Riot Games, Epic Games and more, players now have access to a deep and growing catalog of PC games on Windows on Arm, including Fortnite, Alan Wake 2 and the new World of Warcraft: Forever, and other top titles coming soon, like League of Legends, Valorant, PUBG: Battlegrounds, Genshin Impact and other top titles on Arm-based Windows PCs. 

And we’re super excited to announce that in 2027, Call of Duty will be coming to RTX Spark™.  

Windows is the home for PC gaming and together with our partners, we’re making Windows on Arm continue that heritage. That means more of the games players love, richer graphics, and less time waiting to get into the action.

Innovation built on a foundation of quality

Innovation only matters when the foundation underneath is great. Over the past year, the team has been hard at work improving Windows quality, and we continue to invest in everyday performance, reliability, and craftmanship that have meaningful impact on the way people experience Windows.

This work has spanned giving customers more personalization and control in places like Windows updates, Start and taskbar, Search, the Windows Insider program, as well as deep investments with our partners to enhance driver quality, reliability and security with our ecosystem.

It has also included significant efforts to make Windows the best destination for developers, including optimizations specific to the developer experience.
