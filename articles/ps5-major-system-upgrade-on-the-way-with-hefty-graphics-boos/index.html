PS5 ‘major system upgrade’ on the way with hefty graphics boost

TheTools · 17.09.2026 13:15 · source · permalink

PS5 Pro is getting a major graphics boost with Sony’s next system update, which makes Enhanced PSSR the default for supported games.

Richard Breslin

PlayStation 5 users are set to receive a major graphics boost later this month when Sony rolls out its next PS5 system update.

PlayStation 5 beta testers are already getting an early look at system software update 14.0, which introduces several improvements, including PSSR 2.0 Enhanced.

Sony's upgraded AI-powered upscaling technology is designed to improve image quality and visual fidelity in supported PS5 games, potentially making them look sharper and more detailed without pushing the console's hardware further. However, there is one major catch: PSSR 2.0 Enhanced is exclusive to PS5 Pro.

How does Enhanced PSSR 2.0 work?

This is Sony’s upgraded AI-powered upscaling technology, designed to take advantage of the PS5 Pro’s hardware. Enhanced PSSR reconstructs lower-resolution images at a higher resolution, helping compatible games deliver sharper, more detailed visuals while maintaining a smooth frame rate.

Following PS5 system software update 14.0, PS5 Pro consoles will have Enhanced PSSR enabled by default. This means you shouldn’t need to manually activate the feature through the console’s system settings.

What else does the PS5 system update 14.0 include?

Alongside Enhanced PSSR, PS5 system software update 14.0 will introduce changes to Bluetooth accessory and console settings on both PS5 and PS5 Pro. If Bluetooth is switched off, the console will no longer enter Rest Mode, while HDMI Link will also be disabled.

When will the PS5 system update 14.0 be released?

As reported by the YouTuber TCMFGamesOFFICIAL, PlayStation 5 beta testers have been using system software update 14.0 for the past couple of weeks, giving Sony time to iron out any issues before its wider release.

Sony has yet to confirm exactly when PS5 system update 14.0 will roll out to all users, but it’s expected to arrive within the coming weeks, potentially before the end of September.
