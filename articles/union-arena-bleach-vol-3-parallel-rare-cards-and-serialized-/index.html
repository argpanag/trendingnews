UNION ARENA: BLEACH Vol. 3 Parallel Rare Cards and Serialized APs Revealed in English — Joseph Writer Anderson

Things are heating up for UNION ARENA as we’re heading into some of the biggest releases of the year. Coming up soon is the release of the first ever UNION ARENA Vol. 3: BLEACH: Thousand-Year Blood War, releasing on November 13, 2026.

While we know the full BLEACH Vol. 3 set list already thanks to it having released in Japan, many Parallel Art cards were revealed in English for the first time.

Like the last few sets, the BLEACH Vol. 3 English Version will include several exclusive Parallel Rare cards that you can get from box toppers. These box toppers can only be found in BLEACH Vol. 3 booster boxes, giving you plenty of reasons to pick up sealed products.

While these alts will be hard to pull from the box topper promo packs, you’re guaranteed one of the below foil cards to bling out your deck with.

Serialized, hand-signed Action Point cards feature Ichigo and Grimmjow

Lastly, the two hand-signed, serialized Action Point cards for the set have been revealed, featuring Ichigo and Grimmjow.

Stay tuned for more BLEACH Vol. 3 English spoilers as we get closer to the release date!
