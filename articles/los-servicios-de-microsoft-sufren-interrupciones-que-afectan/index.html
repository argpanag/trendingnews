Los servicios de Microsoft sufren interrupciones que afectan a cientos de miles de usuarios

TheTools · 12.11.2026 23:31 · source · permalink
  • MSFT
    +0,13%

Investing.com - Los servicios de Microsoft, incluidos Outlook, Teams y Microsoft 365, experimentaron interrupciones el jueves, afectando a miles de usuarios en Estados Unidos.

El sitio web de seguimiento de interrupciones Downdetector.com registró más de 130.000 informes de problemas con Outlook a las 19:27 horas. La plataforma realiza un seguimiento de las interrupciones recopilando informes de estado de múltiples fuentes. El número real de usuarios afectados puede diferir de los incidentes notificados.

Microsoft declaró a primera hora del jueves que había resuelto una interrupción de Teams que afectaba a usuarios en Norteamérica y que el impacto había sido completamente subsanado.

La compañía indicó posteriormente que el problema podría afectar también a la conectividad del servicio Microsoft 365 para usuarios en otras regiones.

Downdetector registró más de 46.000 informes de usuarios con problemas en Microsoft 365 y aproximadamente 3.000 informes de usuarios con dificultades para acceder a Teams.
