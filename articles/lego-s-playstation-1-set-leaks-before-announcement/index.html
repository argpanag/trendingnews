Lego's PlayStation 1 set leaks before announcement

TheTools · 03.09.2026 16:03 · source · permalink

Following a leak that revealed that Lego plans to release a new set based on the original PlayStation console, the same source has now shared images of the set, thus giving us a first look.

According to a post by Brick Tap on Instagram, the set, which is due for release on October 1, 2026, was found in a store by a member. The specific store  wasn't revealed, but it can be presumed that Lego has already began shipping the PlayStation set to its own retail stores as well as partner stores.

As reported previously, the PlayStation set will have 1,911 pieces and will cost $160. The images show the two set includes two dioramas — Gran Turismo and Ape Escape — which can be removed and displayed on their own.

The set also comes with a controller  that can be detached from the console. However, a handful of comments have noted the irony as the included controller lacks thumbsticks, while Ape Escape, which is the first game to require analog sticks, is one of the two dioramas. There are also more than a few jokes of the set being available digitally in relation to PlayStation's decision to go all-digital in 2028.

The new leak also reiterates that all purchases of the Lego PlayStation set will include a free Astrobot set while supplies last.
