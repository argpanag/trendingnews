An emergency light was turned on on a server that operates an Internet shopping mall or a corporate homepage. This is because a series of security flaws have been discovered that can allow hackers to break into servers from outside even if they do not know their IDs or passwords.

According to the information technology (IT) industry on the 26th, the Node.js (Node JS) project announced through an official security notice on the 21st that a vulnerability (CVE-2026-111497) that could allow remote code execution was found in the Brotli decompression module included in Node.js.

Earlier, serious security vulnerabilities were also found in PHP, a program widely used for website operation. The vulnerability allows an attacker to remotely execute arbitrary code on a server without separate authentication to take control of the environment or read process memory.

PHP and Node.js are key technologies that are invisible to users but help Internet services work. When you order a product from a shopping mall or log in to the website, it plays a role in allowing the server to handle it. Simply put, it is an invisible worker who helps websites work properly.

The problem is that loopholes that hackers can exploit have been found in these programs. In particular, in Node.js, it was confirmed that an error occurred in the process of unlocking the compressed data. If a hacker exploits it, it may stop the server or run a malicious program.

The high risk is that it can attack without going through a normal login process.

Developers have already distributed updates that have fixed security flaws. The Korea Internet & Security Agency (KISA) also recommended that companies and institutions using related programs apply the latest security updates.

Tiori, a Korean cybersecurity company, has also responded. Tiori, a cybersecurity company, completed its own reproduction and verification of "Node2Shell (CVE-2026-111497)" and released an emergency response guide for companies and institutions.
