ColorOS 17 October 2026 upgrade rolling out in China; Check out the list of eligible devices - The Tech Outlook

TheTools · 16.10.2026 10:16 · source · permalink

In the month of September, ColorOS 17 was officially introduced in the Chinese market, and a few days ago, this upgrade was unveiled in the global market as well.

Now, the ColorOS 17 October 2026 upgrade has started rolling out in China and includes various new features and optimisations for eligible devices.

ColorOS 17 October 2026 upgrade

New Features

Xiaobu’s memory

  • Optimisation of casual note experience: Supports AI summarisation, quickly organising recorded content and bringing scattered notes to a neat and organised state.
  • Add desktop card: Supports adding “Notes” and “My Bills” cards to the desktop and quick view.

AI features

  • Experience optimisation and upgrade: Supports sharing object recognition and transition results in image format. Supports document scanning, exporting, and printing; scanned documents can be exported as PDF, Word, PPT, and Excel formats.

Content Portal

  • Added link card drag and drop: Supports dragging and dropping linked cards from chat conversations to other applications after long-pressing, making cross-application use simpler.

Smart Car

  • Car screen projection upgrade: Supports full-screen playback and automatically hides the taskbar for a more immersive viewing experience.
  • Supports parallel windows, allowing two windows for the same application, making operation more convenient.

More Useful Features

Translate

  • The simultaneous interpretation content report function allows you to save the translated text and recording to your notes.
  • Hindi and Spanish offline translation pack.

Device interconnection

  • Added animation effects for the first connection between mobile phone and car screen mirroring, making the connection status more intuitive.

Mobile/Tablet butler

  • New: The fraud reporting function allows users to report suspected fraudulent phone calls, text messages, websites and other information.
  • Optimisation: The file cleanup module supports categorised cleanup by type, such as large folders, old files, duplicate files and documents.

Oppo AI

New

  • Supports displaying Douyin group-buying coupons awaiting redemption on Xiaobu’s suggestion and Fluid Cloud.
  • Xiaobu Memory supports generating memories by importing images and taking photos with the camera; multiple related images can be combined into one memory.

Optimisation

  • Xiaobu Assistant AI Briefing supports the fusion and analysis of multi-dimensional information, and proactively provides personalised suggestions based on your itinerary, schedule, and personal habits.
