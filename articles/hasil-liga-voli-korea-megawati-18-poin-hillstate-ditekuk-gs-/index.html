Hasil Liga Voli Korea: Megawati 18 Poin, Hillstate Ditekuk GS Caltex

TheTools · 11.11.2026 18:34 · source · permalink

Hillstate menelan kekalahan ketiga beruntun setelah takluk 0-3 (27-29, 16-25, 17-25) dari GS Caltex pada machday ketiga Liga Voli Korea di Suwon Gymnasium, Rabu (11/11) malam WIB.

Penggawa Hillstate asal Indonesia, Megawati Hangestri Pertiwi sejatinya sudah tampil bagus. Mega jadi top skor tim dengan mencetak 18 poin di pertandingan ini.

Namun, kontribusi Megawati itu belum cukup untuk membantu Hillstate keluar dari periode negatif karena selalu kalah dari tiga laga awal yang sudah dilakoni.

Hillstate dan GS Caltex melakoni duel sengit di set pertama. Hillstate sempat unggul satu poin dalam kedudukan 8-7 atas GS Caltex.

Namun, situasi berubah memasuki pertengahan set pertama. GS Caltex bisa unggul 15-13. Setelah itu pertarungan berjalan ketat dengan skor imbang terjadi hngga skor 25-25 dan 27-27.

Hillstate yang sempat unggul 26-25 pada akhirnya takluk 27-29 dari sang lawan di set pertama.

Hyundai lantas kesulitan di set kedua. Megawati dan kawan-kawan bahkan tertinggal 10-17 dari GS Caltex.

Situasi sulit ini tidak bisa diatasi hingga akhirnya GS Caltex menutup set kedua dengan keunggulan 25-16.

Hillstate coba memperbaiki situasi di set ketiga. Hasilnya, Hillstate yang dilatih Kang Sung-hyung bisa unggul 10-7.

Hanya saja, Hillstate tak bisa mengendalikan keunggulan ini. GS Caltex bisa membalikkan keadaan untuk berbalik unggul hingga skor 12-18.

GS Caltex semakin di atas angin. Momentum bagus itu dipertahankan mereka untuk menutup set ketiga dengan skor 25-17 untuk menang dengan skor meyakinkan 3-0.
