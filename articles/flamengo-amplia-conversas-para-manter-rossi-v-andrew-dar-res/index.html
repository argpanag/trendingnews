Flamengo amplia conversas para manter Rossi, vê Andrew dar resposta, mas analisa alternativas jovens para o gol

A diretoria do Flamengo aproveitou a ida a Argentina para o jogo com o Estudiantes pela Libertadores para estreitar conversas com representantes do goleiro Rossi para ampliar o vínculo que vence em 2027.
