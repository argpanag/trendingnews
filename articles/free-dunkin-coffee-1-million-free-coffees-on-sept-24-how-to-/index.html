Free Dunkin' coffee: 1 million free coffees on Sept. 24 — how to claim

TheTools · 24.09.2026 09:02 · source · permalink

TL;DR: Dunkin' is giving away 1 million free drinks on Sept. 24. The promo code will drop at some point during the day, so keep this page bookmarked for an update.

Dunkin' is giving away 1 million free drinks, again. That seems like an absolutely wild promotion, but Dunkin' actually does this kind of thing fairly regularly. That doesn't make it any less exciting, and the process of claiming remains the same.

Dunkin' doesn't release specifics on what's actually included in the giveaway until the promo code goes live. That code is expected to drop sometime on Sept. 24, after which point everyone will rush to claim one of the free drinks. We'll be keeping a keen eye on all the usual channels to bring you that code as soon as it goes live. These freebies go quickly, so you need to be ready.

Once the code goes live, you'll need to enter it in the "Offers & Rewards" section of your app. Yes, that does mean you need to be a Dunkin' Rewards member, but it's free to sign up, and this type of giveaway comes around pretty often. It's worth the hassle.
