Z.ai Releases GLM-5.4 to Coding Plan Subscribers

TheTools · 23.11.2026 07:08 · source · permalink

Z.ai has made GLM-5.4 available to all GLM Coding Plan subscribers, introducing vision capabilities and expanded usage allowances as the Chinese artificial intelligence developer advances its coding model lineup. The company confirmed the rollout on November 23, 2026, positioning the subscription service as the initial confirmed access channel.

The release brings image-processing capabilities to the GLM-5.4 flagship, marking a departure from the text-only GLM-5.3 model. Z.ai also claims that the new version delivers stronger coding performance, although its announcement did not include benchmark scores supporting the improvement.

According to Z.ai, subscribers subject to weekly usage limits receive 50% more GLM-5.4 quota than they received with GLM-5.3. However, the company has not published new five-hour limits, individual subscription-tier credit allocations, or a specific formula for converting model usage into credits.

Z.ai lists its Coding Plan starting at US$18 per month. Subscribers can access GLM-5.4 through supported development environments, including ZCode, Claude Code, and OpenCode. Users can select the model through their coding client's model selector or configuration settings.

The company has not yet documented which image formats GLM-5.4 supports or established publicly available limits for visual inputs. Developers planning screenshot-based workflows therefore lack complete technical specifications for evaluating the model's image-processing capabilities.

GLM-5.3-Flash already supports image, video, and file inputs, providing an existing multimodal option within Z.ai's model lineup. GLM-5.4 adds vision support to the flagship coding model, although the available announcement does not establish whether its capabilities match those of the Flash variant.

Access through the standard application programming interface also remains unconfirmed. Z.ai's published API pricing documentation does not list GLM-5.4, and the public OpenRouter model catalog checked on November 23 contained no dedicated listing for the new version.

Z.ai maintains separate billing arrangements, API keys, and endpoints for Coding Plan subscriptions and its standard API service. Consequently, the confirmed subscription availability does not establish that developers can access GLM-5.4 through existing pay-as-you-go API credentials.

Other technical details remain unpublished. Z.ai has not provided an official parameter count, maximum output length, downloadable model checkpoint, or license for GLM-5.4. Although IT Home reported that the Chinese Coding Plan selector displays a 1M label, the exact context-window specifications have not been established in the company's model documentation.

Independent performance evaluations are also unavailable. Artificial Analysis's Intelligence Index v5.0.1 lists GLM-5.3 Max at 32 points and GLM-5.3-Flash at 28 points, while GLM-5.4 has no published result. These figures provide comparisons for earlier models but cannot establish the new release's performance.

A separate ChinaZ headline also previewed a forthcoming 3-trillion-parameter flagship from Zhipu for December 2026, distinguishing that anticipated release from the GLM-5.4 rollout. The available information does not establish additional specifications or confirm that both announcements concern the same model.

As of November 23, 2026, GLM-5.4 is available to GLM Coding Plan subscribers, while standard API access, independent benchmarks, downloadable weights, and complete technical specifications remain unverified.
