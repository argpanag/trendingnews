Developers have released the Leonida tool for natively running Grand Theft Auto VI on PC.

TheTools · 23.11.2026 21:04 · source · permalink

Leonida, an open source project aimed at statically recompiling the console version of Grand Theft Auto VI for Xbox Series X into a native OS application, has appeared on the GitHub platform. WindowsSince the console processor uses the x86-64 architecture, the authors of the initiative translate the console system calls into the PC environment, and translate the compiled RDNA2 graphics programs into the SPIR-V format for operation via the API. VulkanThe project is distributed under the GPL-3.0 license and does not contain any copyrighted game files, encryption keys, or executable modules. To build the port, the user will need an unpacked copy of version 1.0.2.1 of the game, from which the utilities will automatically extract the necessary assets and generate shaders locally on the computer.

At this stage the game does not launch yet, as the developers lack an executable file to complete the work on the loader and the D3D12 graphics layer for VulkanHowever, the toolkit already successfully extracts and converts all 26 game shaders to SPIR-V, as well as exports 503D models to OBJ format, textures to DDS, and audio tracks to Ogg Opus or WAV. Building the project independently on a PC requires certain software and hardware requirements.

  • A native copy of the game for Xbox Series version 1.0.2.1 with readable files.
  • Operating system Windows 10 or Windows 11 x64 with about 350 GB of free disk space for work files.
  • Python interpreter version 3.12 or later installed and added to the PATH variable.
  • .NET 8 SDK and Toolset Vulkan SDK for running the spirv-as and spirv-val utilities.
  • LLVM 21 or later compiler with AMD target architecture supportGPU for the llvm-mc utility.
  • Visual Studio 2022 with C++ Desktop Components and Pack Windows SDK version 10.0.26100 or later.
  • The ffmpeg utility in the PATH variable for decoding XMA2 audio streams and converting to WAV format.

The automated build script automatically finds the game folder on local drives using the MicrosoftGame.Config configuration, checks for the presence of the required components, and saves the finished result in the user's documents directory. WindowsThe process of resource extraction and shader validation is supported on Linux, where the executable loader can be launched via Wine or Proton. The project's repository already has over 8,2 stars and 147 contributors, who continue to refine the translation of graphics commands and the emulation of 64-thread shader groups for NVIDIA and Intel graphics cards.
