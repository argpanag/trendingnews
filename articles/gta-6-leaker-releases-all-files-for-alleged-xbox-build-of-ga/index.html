GTA 6 Leaker Releases All Files for Alleged Xbox Build of Game

TheTools · 23.11.2026 16:26 · source · permalink

'Xmas came early,' the CyberLeek gang says. If real, the dumped executable program promises to help the modding community create a PC port for Grand Theft Auto 6 soon.

Getting your Trinity Audio player ready...

The CyberLeek hacking gang claims to have released a key executable program that promises to help the modding community port Grand Theft Auto 6 to the PC. 

On Monday, the group updated its website, posting a link to the 57MB archive that contains the executable program. “The exe is out. Always free. An early Christmas gift from CL,” CyberLeek wrote in a post titled “Xmas came early.”

The archive supposedly completes the stolen Xbox build for GTA 6 that CyberLeek initially began circulating last week via a 209GB torrent containing files for Rockstar’s RAGE game engine and the Xbox console. CyberLeek now suggests that the file dump will be enough for the modding community to recompile the game to run on a PC, since the Xbox platform runs on an OS based on Microsoft Windows. 

“The torch passes to the open source recomp and emulation projects,” the gang says. CyberLeek also appears to have settled for merely asking for donations to the group’s meme coin after its previous efforts to drive up the coin's market cap flopped. 

One community GTA 6 recompilation project, Leonida, has been examining the leaked executable files. Traffic has been so high that the group’s chat server on Discord malfunctioned, appearing to crash. However, an admin later posted: “It will take at least a week for us to get somewhere noticeable to the point where you can play on your pc.” To avoid the project from being taken down, the admin added: “We will not be giving assets whatsoever; you will need to download the game yourself.”

"This .exe file does NOT RUN THE GAME," an admin also posted before the leak dropped. "This will be used by the developers to work with and make the actual recomp, which will use the game files and exe to build the port."

In the meantime, users in the project have been using AI coding tools and agents, including Anthropic’s Claude, to reverse-engineer and try to get the leaked game files running on Windows. “THE GAME ALMOST BOOTS. BLACK SCREEN, AUDIO CUTS OFF,” claimed one user in the Discord chat. 

Recommended by Our Editors

So far, Rockstar Games and its parent, Take-Two Interactive, haven’t responded to a request for comment. But developers are rumored to be preparing an official PC release for GTA 6 as soon as next year’s first quarter. Still, a pirated PC port could go viral and sap sales for the game, which is currently exclusive to the PlayStation 5 and Xbox Series X/S. 

The dumped files also suggest CyberLeek was able to infiltrate and steal an Xbox copy of GTA 6 well before the game officially launched. Although Take-Two subpoenaed the major platforms, including Microsoft, for records to try to uncover the leaker, CyberLeek remains at large.
