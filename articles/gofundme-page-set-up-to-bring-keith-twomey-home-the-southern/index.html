GoFundMe page set up to bring Keith Twomey home | The Southern Star

TheTools · 13.10.2026 21:08 · source · permalink

A GoFundMe page has been set up to raise funds to help bring Keith Twomey from Ballineen home from Rhodes, following a road traffic accident on the island last month.

The 52-year-old suffered brain injuries and five fractures following the accident on September 11 and has remained in hospital almost four weeks later.

The GoFundMe page was set up by Keith's brother Graham yesterday and has so far raised over €44,000 as the people of West Cork and beyond contribute to the costs so that Keith can be brought home.

The family felt this was the only option forward after pleading with both the Government and the HSE to help bring Keith home.

See https://www.gofundme.com/f/keith-twomey-home-from-rhodes-for-urgent-medical-attention
