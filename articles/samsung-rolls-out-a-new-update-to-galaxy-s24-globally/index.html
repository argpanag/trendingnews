It's not One UI 9.0 (Android 17).

Abhijeet Mishra / SamMobile

Samsung Galaxy S24 Ultra

Samsung has released new software updates for the Galaxy S24, Galaxy S24+, Galaxy S24 Ultra, and Galaxy S24 FE. Unfortunately, it doesn’t bring the stable version of One UI 9.0 (Android 17), which the phones’ users have been waiting for eagerly. Instead, it offers the September 2026 security patch, which fixes 90 security issues.

The brand is rolling out these updates globally. The update for the international variants of the regular, Plus, and Ultra models is 450.43MB in size and carries firmware version S92xBXXSHDZI1 (via Tarun Vats). Whereas the update for the Galaxy S24 FE is 438.23MB in size and carries firmware version S721BXXSEDZI1 (via @Alfaturk16).

To get the latest firmware available on your Galaxy S24, go to Settings > Software update > Check for updates. At the moment, there’s no information on when these phones will get the stable version of One UI 9.0.

On a related note, Samsung has also started rolling out the October 2026 security patch to its smartphones, with the Galaxy S26 series being the first to get it. The brand may offer it to the Galaxy S24 with the stable One UI 9.0 update.
