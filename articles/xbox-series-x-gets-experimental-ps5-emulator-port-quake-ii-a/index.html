Xbox Series X Gets Experimental PS5 Emulator Port, Quake II Already Running

TheTools · 28.09.2026 15:06 · source · permalink

Sunday, September 20th 2026 Xbox Series X Gets Experimental PS5 Emulator Port, Quake II Already Running A developer has apparently gotten an experimental PS5 emulator running on the Xbox Series X. Devran Cosmo Uenal, who posted about the project on YouTube on September 8, calls it a research project that ports the open-source KytyPS5 emulator to Microsoft's console through Developer Mode. Uenal shows GEX Trilogy, Hellboy: Web of Wyrd, Marvel Cosmic Invasion, and Quake II in his game library and claims they all work with controller input, with sound working in some of them. He also says AI tools were used, but it's unclear how much of the code they wrote. Compatibility is very limited, and Uenal says a lot of work is left. According to him, the Xbox environment doesn't support Vulkan, which KytyPS5 uses for rendering, so the graphics side has to be adapted to DirectX. That likely means progress on the PC version won't carry over automatically. We haven't seen performance benchmarks either, but the video shows Quake II running somewhere between 25 FPS and 45 FPS. The game also dips below 20 FPS in some scenes, especially when it first boots up. There is also a marked jump in input latency that can be observed, but no numbers back it up yet. The KytyPS5 emulator itself is still in its early phases, though it has moved quickly. TechPowerUp covered it taking Demon's Souls Remake from unplayable to 30 FPS in days, and it recently got the PS5 version of GTA 5 running at up to 60 FPS on a high-end PC. Emulation usually comes at a big performance cost. Running the heavier PS5 games using this emulator will be a big challenge, since the Series X and PS5 have generally similar hardware. Lighter titles might get there, though. Nonetheless, it is a very neat technical demo and shows just how fast emulation is progressing. Source: Devran Cosmo Uenal
