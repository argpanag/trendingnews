How to redeem codes in Grand Blue explained

Redeeming Grand Blue codes is super simple, and there are two ways to do it.

How to redeem Grand Blue codes from the main menu

  • Launch Roblox
  • Select Customise Character
  • Enter a code in the Codes Box in the bottom right of the screen
  • Press Redeem

How to redeem Grand Blue codes in-game

If you’re already in a server, you need to follow these steps:

  • Select the Settings menu in the top right
  • Select the Codes tab
  • Enter a code and press Redeem
