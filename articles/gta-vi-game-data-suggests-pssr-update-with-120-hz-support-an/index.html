GTA VI Game Data Suggests PSSR Update With 120 Hz Support and PS5 Pro "High CPU Frequency Mode"

TheTools · 10.11.2026 00:01 · source · permalink

Monday, November 9th 2026 GTA VI Game Data Suggests PSSR Update With 120 Hz Support and PS5 Pro "High CPU Frequency Mode" With the GTA VI launch around the corner, more and more information has begun to surface about the upcoming game. The latest news comes from GTAForums user Tex2, who analyzed the GTA VI PS5 metadata, who claims that GTA VI will launch alongside a newer version of PSSR. The biggest takeaways from this update are that the new PSSR game mode improves both the framerate capabilities of the PlayStation 5 and manages to eke out some more CPU performance out of the PlayStation 5. The metadata lists PSSR (or MFSR, by Sony's internal references) version 13.60, which builds on the 13.00A found in Assassin's Creed Shadows and Cyberpunk 2077, and the new version will apparently include a 120 Hz mode that drops support for VRR. It may also include a 40 FPS mode as a stop-gap to make up for the lack of VRR, but that hasn't been confirmed by the metadata. It will also enable a CPU High Frequency mode on the PlayStation 5, which may be necessary to enable higher frame rates in GTA VI. Sources: Tex2 on GTAForums, via Twised Voxel
