Second PS5 System Update for October 2026 Rolled Out - AOL

TheTools · 25.10.2026 13:04 · source · permalink

Sony Interactive Entertainment has stealth-dropped PS5 system software update 26.07-14.20.00 — the second firmware update for October 2026. Like the previous update, don’t expect anything exciting from this one.

PS5 system software update 26.07-14.20.00 patch notes (October 21, 2026)

“We’ve improved the messages and usability on some screens,” the lone patch note reads. So, just a minor update that doesn’t do anything noteworthy.

That said, Sony sometimes makes changes it doesn’t advertise. If we spot anything different or hawk-eyed fans notice something new, we’ll share it with our readers.

There’s still no word of a wider rollout of the base PS5’s surprising new Quick Spectral Super Resolution (QSSR) feature. The PS5 Pro-like AI upscaler is already available to first-party devs but has not been implemented in third-party games yet.

Advertisement

“While PSSR remains the gold standard on PS5 Pro, QSSR provides some notable improvements to both image detail and image stability on PS5,” Sony explained.

In case you missed it, QSSR utilizes the following innovations:

  • A streamlined neural network architecture

  • A hand-tuned implementation that maximizes performance on PS5

We’ll update our readers when we have more information. At the time of this writing, there have been no further system software updates for the PlayStation Portal.
