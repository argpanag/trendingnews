FritzOS 8.50 mit Adblocker-Funktion ist fertig

TheTools · 04.10.2026 22:56 · source · permalink

Die Fritzbox 7690 bekommt als Erstes das finale FritzOS 8.50. Kernfunktion ist ein DNS-Filter, der Werbung auf allen Geräten im Heimnetz blockt.

(Bild: Fritz)

  • Mark Mantel

This article is also available in English. It was translated with technical assistance and editorially reviewed before publication.

Fritz beginnt mit der Verteilung seines nächsten großen Firmware-Updates FritzOS 8.50. Als Erstes bekommt das DSL-Modell Fritzbox 7690 mit Wi-Fi 7 die neue Version. Nutzer können das Update in der Weboberfläche anstoßen, bei aktivierter Auto-Update-Funktion kommt es automatisch. Standardmäßig ist sie im Browser über fritz.box oder die lokale IP 192.168.178.1 erreichbar.

Der Hersteller will FritzOS 8.50 laut Ankündigung in den kommenden Wochen für weitere „aktuelle Fritzbox- und Fritz-Repeater-Modelle“ freigeben. Konkrete Modelle nennt die Firma wie üblich nicht. Mindestens Router, die entsprechende Labor-Vorabversionen erhalten haben, bekommen das finale FritzOS 8.50 ziemlich sicher. Das wären folgende Fritzboxen:

  • Glasfaser: 5690 Pro, 5690, 5690 XGS, 5590
  • DSL: 5690 Pro, 7630, 7590 AX, 7590, 7530 AX
  • Kabel: 6690, 6670, 6660
  • Mobilfunk: 6850 5G v2, 6850 5G, 6850 4G/LTE
  • Modemlos: 4690, 4050

(Bild: heise medien)

Integrierter Adblocker

Die wichtigste neue Funktion von FritzOS 8.50 sind Filterlisten für das Domain Name System (DNS). Damit lassen sich die Server von Werbetreibenden blockieren, sodass deren Einblendungen gar nicht erst auftauchen. Auch bestimmte Trackingserver laufen dann ins Leere. Das Ganze funktioniert im gesamten Heimnetzwerk, das über den Router läuft, sowohl im WLAN als auch über Ethernet (LAN). Mit den richtigen Filterlisten sollten sich also auch auf dem Smartphone keine Werbebanner und keine ungewollten neuen Tabs mehr öffnen.

„Fritzhole“: Adblocker direkt in Fritzboxen nutzen

Außerdem priorisieren Fritzboxen mit dem Update automatisch echtzeitrelevante Anwendungen, etwa Spiele-Traffic oder Videokonferenzen. Bisher funktionierte die Priorisierung pro Client (etwa PCs oder Smartphones), jetzt auch pro Anwendung auf einem einzelnen Gerät. Eine Funktion betrifft ausschließlich Mobilfunk-Fritzboxen, sobald sie das Update bekommen: Sie können dann einen Internetzugang über LAN nutzen, etwa über ein vorgeschaltetes Glasfasermodem. Fällt diese Verbindung aus, springt der Mobilfunk als Ausfallschutz ein.

Einfacher Einstieg

Die MyFritz-App für Smartphones erhält eine neue Übersichtsseite, die den aktuellen Zustand einer Fritzbox zusammenfasst. Hat der Router FritzOS 8.50 installiert, meldet er Empfehlungen, Hinweise und Warnungen an die App. Damit sollen die Geräte einstiegsfreundlicher werden.

Wer die Smart-Home-Funktionen von Fritz verwendet, bekommt neue Routine-Möglichkeiten. Für Fritz-Telefone kommt ein „Einfacher Modus“, bei dem sich etwa alle Auswahltasten als Schnellwahltasten konfigurieren lassen. Zusätzlich gibt es einen SOS-Ruf: Bei Notfällen soll das Telefon nacheinander eigenständig bis zu vier hinterlegte Nummern anrufen.
