Susunan Pemain Borneo FC Vs Java United: Pesut Etam Turunkan M Kadu

TheTools · 11.10.2026 08:35 · source · permalink

Borneo FC Samarinda akan menghadapi Java United FC dalam lanjutan BRI Super League 2026/2027 pekan ke-4. Kiper Aldo Geraldo Manuel Monteiro (M Kadu) masuk dalam daftar 11 pemain utama Pesut Etam pada pertandingan ini.

Laga Java United FC vs Borneo FC Samarinda digelar di Stadion Jatidiri, Semarang, Minggu (11/10/2026) pukul 16.30 Wita. Laga tersebut dipimpin wasit Naufal Adya Fairuski.

Berdasarkan daftar susunan pemain, Borneo FC menurunkan M Kadu sebagai penjaga gawang. Dia akan didukung barisan pertahanan yang diisi Van Basty Sousa e Silva, Komang Teguh Trisnanda, Juan Felipe Villa Ruiz (Villa), dan Reva Adi Utama.

Di lini tengah, Borneo FC menyiapkan Marcos Emanuel Astina (Astina), Ikhsan Nul Zikrak, serta Iago Pereira Mendonca. Sementara itu, Christian Matheus Lima da Silva (Christian), Hugo Samir, dan Mussa Diarra menjadi pilihan di lini serang.

Di kubu lawan, Java United menurunkan Jorge Meurer Bartholdy sebagai penjaga gawang. Gustavo Moreno de Franca (G. Franca) yang bertindak sebagai kapten akan mengisi lini belakang bersama Christian Gomes dan Kei Hirose.

Java United juga mengandalkan Gustavo Almeida dos Santos (Gustavo) di lini depan. Dia akan didukung Yabes Roni Malaihani, Fret Lisanto Butuan, serta pemain lainnya untuk membongkar pertahanan Pesut Etam.
