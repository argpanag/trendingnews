Fortinet issues urgent out-of-band updates, but offers few details

TheTools · 23.10.2026 04:03 · source · permalink

Fortinet will release updates Thursday that admins should install urgently. Details won’t come until November.

(Image: JHVEPhoto/Shutterstock.com)

  • Dirk Knop

Fortinet has announced unplanned updates for several products. They are due to arrive sometime Thursday this week. The vendor is urging IT administrators to install them immediately.

That’s according to a blog post from Fortinet. A set of security updates is coming for FortiOS, FortiManager, and FortiAnalyzer, following new releases for FortiAuthenticator and FortiMail. The company strongly urges every customer to plan and carry out the update immediately once the updates are available. Internet-facing devices should be first. Anyone who can’t update right away should temporarily reduce their attack surface, Fortinet says: restrict admin access over HTTPS and SSH to trusted IP addresses or disable it on external interfaces, and manage devices through a separate management network.

Urgent updates after AI vulnerability hunting

The vendor uses frontier AI models in its security testing program and thanked Anthropic, Google, OpenAI, and SpaceX, which has since been acquired by xAI, for their collaboration. The releases now announced address critical and high-risk vulnerabilities found by artificial intelligence. Fortinet is full of praise: AI analyzes code paths, protocol handling, and configuration logic at a depth and speed that traditional fuzzing and manual review could not achieve.

The models have now been able to uncover vulnerabilities Fortinet can proactively fix before malicious actors exploit them. The company sees this as putting its “Secure-by-Design” commitment into practice. But that implies the same AI capabilities are also available to attackers, further shrinking the window between disclosure and exploitation.

“Critical and high risk”

Customers should apply the updates immediately because the releases include fixes for critical and high-risk issues. AI tools could help bad actors reverse-engineer the patches and develop working exploits in hours or days instead of weeks. The patches themselves reveal where changes were made and can therefore expose the vulnerabilities, making unpatched machines easier targets for an attack. There is also a risk that AI could help link vulnerabilities with lesser impacts to reach a more serious, exploitable security hole.

New versions of the following software are due by Thursday at the latest and will include the fixes:

  • FortiOS 8.0.2, 7.6.8, 7.4.13 and 7.2.14,
  • FortiManager 8.0.2, 7.6.8, 7.4.12 and 7.2.13,
  • FortiAnalyzer 8.0.2, 7.6.8, 7.4.12 and 7.2.13,
  • FortiMail 8.0.2, 7.6.7 and 7.4.9 (users of 7.2.x should migrate to 7.4 or later),
  • FortiAuthenticator 8.0.4 and 6.6.11

Fortinet assures customers that newer versions also close the vulnerabilities discovered. FortiSASE is due to update automatically by Thursday. FortiManager Cloud updates should be available by Thursday but may need to be installed manually. The vendor plans to publish security advisories with details about the vulnerabilities on its next Fortinet Patch Day, Nov. 10, 2026.

Because Fortinet devices usually control network access as firewalls or VPN gateways, attackers are particularly interested in vulnerabilities in them. Just this Monday, warnings about ongoing attacks on several Fortinet products became public.
