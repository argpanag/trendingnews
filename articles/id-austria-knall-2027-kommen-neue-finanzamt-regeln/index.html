ID Austria-Knall: 2027 kommen neue Finanzamt-Regeln

TheTools · 10.11.2026 08:09 · source · permalink

FinanzOnline

Mit einer neuen FinanzOnline-Verordnung wird der Zugang zum Steuerportal des Finanzministeriums neu geregelt. Die ID Austria wird zum Standard, klassische Zugangsdaten werden schrittweise abgeschafft. Auch bei der Übermittlung von Anträgen gelten künftig strengere Vorgaben.

Strom wird 2027 etwas billiger

Die Verordnung tritt am 1. Jänner 2027 in Kraft und ersetzt die bisherige Regelung aus dem Jahr 2006.

ID Austria wird zum Standard

Für die Anmeldung gibt es künftig drei Möglichkeiten: die ID Austria, eine elektronische Identität aus einem anderen EU-Staat oder klassische Zugangsdaten mit zusätzlicher Zwei-Faktor-Authentifizierung. Wer die ID Austria verwendet, benötigt keinen weiteren Sicherheitscode. Die Anmeldung per Fax wird abgeschafft.

Alte Zugangsdaten laufen aus

Privatpersonen erhalten ab 2027 grundsätzlich keine neuen klassischen Zugangsdaten mehr. Ausnahmen gibt es etwa, wenn die Nutzung der ID Austria nicht möglich oder zumutbar ist. Bestehende Zugänge sollen mit 1. Oktober 2029 endgültig deaktiviert werden. Teilweise kann das Finanzamt sie auch früher sperren.

Bis zu 700 Euro Strafe möglich

Für rund 130 Arten von Eingaben wird künftig eine bestimmte Funktion in FinanzOnline vorgeschrieben. Wer trotz Aufforderung wiederholt den falschen Übermittlungsweg nutzt, riskiert unter bestimmten Voraussetzungen eine Mutwillensstrafe von bis zu 700 Euro. Die Arbeitnehmerveranlagung bleibt weiterhin auch auf Papier möglich.

Wer noch klassische Zugangsdaten nutzt, sollte rechtzeitig auf die ID Austria umsteigen.
