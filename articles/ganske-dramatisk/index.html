Mange varsel om problem med nedlasting få timar før «GTA 6»-lanseringa.

Det blei meldt om store problem for dei som ventar på å få lasta ned «GTA 6» i tide før lanseringa ved midnatt onsdag.

Downdetector skriver på X at brukarar har meldt om problem med Playstation-nettverket (PSN) sidan i føremiddag.

Onsdag kveld stadfestar PSN sjølv at det er trøbbel.

«Du kan oppleve problem med å starte spel, appar eller nettverksfunksjonar. Vi jobbar med å løyse problemet så snart som mogleg. Takk for tolmodet», stod det på nettsidene deira.

Denne meldinga blei fjerna rundt klokka 20.30 og no står det på PSN si side at «alt fungerer».

Rune Fjeld Olsen er spelanmeldar og er ein av dei som har gledd seg lenge til lanseringa av nye «GTA». Foto: Gunnar Bratthammer / NRK

Spelanmeldar i NRK, Rune Fjeld Olsen, meiner det som skjer onsdag kveld kan vere ganske dramatisk.

– Viss du har venta til siste liten med å førehandsinstallere det, så er eg ikkje overraska. Men viss det i tillegg betyr problem med å logge inn på Playstation Network og rett og slett få tilgang til kontoen din, så vil eg jo seie det er ganske dramatisk.

Han peikar på at plattformene har skalert opp for det dei trur er maks tal samtidige brukarar.

– Så kjem det inn noko slikt som dette som sprengjer alle dei skalaene som dei har operert etter, seier Olsen.
