Apple Announces macOS Golden Gate Release Date

TheTools · 10.09.2026 20:38 · source · permalink

Apple this week announced that macOS 27, also known as macOS Golden Gate, will be released to all users with a compatible Mac on Monday, September 14.


iOS 27, iPadOS 27, watchOS 27, tvOS 27, and visionOS 27 will be released on the same day.

macOS Golden Gate features Siri AI, design improvements, performance enhancements, and more. A developer beta has been available since June, while a public beta followed in July, and now the update will be widely released on September 14.

macOS Golden Gate is compatible with all Macs with an M1 chip or newer:

  • MacBook Neo (2026)
  • MacBook Air with Apple silicon (2020 and later)
  • MacBook Pro with Apple silicon (2020 and later)
  • iMac (2021 and later)
  • Mac mini (2020 and later)
  • Mac Studio (2022 and later)
  • Mac Pro (2023 and later)

macOS 26 aka macOS Tahoe is the final macOS release compatible with Intel-based Macs.

Intel Macs that can run macOS Tahoe, but not macOS Golden Gate:

  • 13-inch MacBook Pro (2020, Four Thunderbolt 3 Ports)
  • 16-inch MacBook Pro (2019)
  • 27-inch iMac (2020)
  • Mac Pro (2019)

Apple said Intel-based Macs will continue to receive security updates for three years.

macOS 27 Golden Gate can still run Intel apps on Apple silicon, as it is the final major macOS release to include Apple's full Rosetta translation layer.
