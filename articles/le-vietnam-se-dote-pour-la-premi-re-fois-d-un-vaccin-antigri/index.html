Le Vietnam se dote pour la première fois d’un vaccin antigrippal en spray nasal destiné aux enfants

TheTools · 29.10.2026 09:40 · source · permalink

Cette solution vient élargir les possibilités de prévention de la grippe sans injection pour les enfants et les adolescents âgés de 2 à moins de 18 ans.

Reposant sur une technologie à virus vivant atténué, le vaccin est administré directement sur les muqueuses nasales. Il stimule trois types de réponses immunitaires: l’immunité muqueuse, l’immunité systémique et l’immunité cellulaire.

Selon VNVC, les données des études font état d’une efficacité préventive pouvant atteindre 88% contre les souches virales apparentées à celles contenues dans le vaccin.

La mise à disposition de ce spray nasal marque une avancée dans le développement de solutions de prévention sans aiguille. Le produit est déjà utilisé dans 34 pays et territoires, avec plus de 200 millions de doses distribuées dans le monde.
