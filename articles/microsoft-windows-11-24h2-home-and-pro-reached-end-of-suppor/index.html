Microsoft: Windows 11 24H2 Home and Pro reached end of support

TheTools · 14.10.2026 00:58 · source · permalink
  • October 13, 2026
  • 03:04 PM

Microsoft announced today that devices running Windows 11 24H2 Home and Pro editions have reached the end of support and will no longer receive monthly security and non-security preview updates.

However, according to Microsoft's lifecycle policy, Windows 11 24H2 Enterprise and Education editions remain under mainstream support until October 12, 2027.

"Today, October 13, 2026, Windows 11, version 24H2 Home and Pro, and Windows 10 Enterprise LTSB 2016 have reached end of updates. The October 2026 monthly security update is the last update available for these editions," Microsoft said in a message center update.

"Devices running these editions will no longer receive monthly security and non-security preview updates containing protections from the latest security threats."

Microsoft advises users to upgrade to Windows 11 26H2, the latest Windows 11 version, also known as the Windows 11 2026 Update, which is now rolling out in phases to eligible Windows 11 devices where the "Get the latest updates as soon as they're available" option has been enabled.

Windows 11 26H2 became generally available in September 2026 as an enablement package and will reach end of support for consumers in October 2029.

"Windows 11, version 26H2 rollout is phased and will expand over the next few months," it added. "If the update is ready for your device, it will download and install automatically, and a single restart will complete the process."

Last week, Microsoft also reminded customers that systems running Windows 11 23H2 Enterprise, Education, and IoT Enterprise editions will also stop receiving security updates in 30 days, after Windows 11 23H2 Home and Pro editions reach end of support in November 2025.

Earlier this year, it extended the free Windows 10 Extended Security Updates (ESU) program for home users and announced that Windows Server 2022 also reaches the end of mainstream support today (but will remain under extended support until October 2031).

More recently, on Thursday, it warned customers to upgrade devices running unsupported versions of Windows as they will stop receiving security updates after next year's Windows Update certificate rotation.

More information about Windows 11 servicing dates is available on the Windows Lifecycle FAQ page or using the Lifecycle Policy search tool.
