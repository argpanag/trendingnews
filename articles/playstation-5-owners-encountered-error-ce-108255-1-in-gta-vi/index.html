PlayStation 5 owners encountered error CE 108255 1 in GTA VI after updating their firmware.

TheTools · 21.11.2026 09:32 · source · permalink

PlayStation 5 owners have begun reporting crashes and freezes in the crime action game Grand Theft Auto VI, accompanied by the system error code CE-108255-1. This issue was most pronounced on base models of the console, including the standard model with a disc drive, the Digital Edition, and the compact Slim version. Interestingly, users have also started experiencing a similar system crash with the same error code in other modern games, such as the football simulator EA SPORTS FC 27, indicating a system-wide issue.

Technical experts and gaming community members attribute the crashes to the recent release of a series of software updates for the PlayStation 5, including the mandatory firmware version 14.23, which Sony released shortly before the global release of Grand Theft Auto VI. According to analysts, the Japanese corporation's engineers failed to conduct comprehensive benchmarking of the latest system patches under peak load conditions, rushing to quickly patch security vulnerabilities and protect the anticipated blockbuster's files from hacking. As a result of the rush, the interaction between the system shell and game executables was disrupted.

Experts also noted a fundamental difference in the operating system architecture between Sony and Microsoft consoles, which explains the more stable performance of the new title on Xbox Series X|S consoles. On Xbox consoles, each game comes with an isolated portion of its own operating system, which is used to develop it, so scheduled updates to the main operating system have virtually no impact on the game's internal runtime. On PlayStation 5, the connection to the latest system software is tighter, meaning that flaws in the latest firmware directly cause app crashes.
