Première pour la charnière Coly - Du Preez, Fickou capitaine... La composition de Bayonne - Toulon

TheTools · 05.09.2026 16:39 · source · permalink

Les Bayonnais de l'Aviron accueillent à Jean-Dauger le Rugby club toulonnais pour la première journée de Top 14. Laurent Travers offre sa première à la charnière Coly - Du Preez. Côté RCT, Gaël Fickou sera capitaine. 

Le XV de départ de Bayonne : 15. Orabé ; 14. Levêque, 13. Maqala, 12. Mori, 11.Tambwe ; 10. Du Preez, 9. Coly (cap.) ; 7. Uhila, 8. Bruni, 6.Fischer ; 5. Paulos, 4. Geraci ; 3. Setiano, 2. Martin, 1. Bordelai.

Remplaçants : 16. Cramont, 17. Cormenier, 18. Alainu’uese, 19. Habel-Küffner, 20. Capilla, 21. Tilloles, 22. Martocq, 23. Tatafu.

Le XV de départ de Toulon : 15. Jaminet ; 14. R. Rebbadj, 13. Smaïli, 12. Fickou (cap.), 11.Ferté ; 10. Garcia, 9. Serin ; 7. Ollivon, 8. Mercer, 6. E.Abadie ; 5.Cancoriet, 4. S. Rebbadj ; 3. Sinckler, 2. Baubigny, 1.Ametlla.

Remplaçants : 16. Damond, 17. Jean-Christophe, 18. Asevedo, 19. Quere-Karaba, 20. Jones, 21. White, 22. L.Keletaona, 23. Slimani.
